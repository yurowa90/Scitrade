# 레퍼런스 조사와 적용 결정

확인일: 2026-10-04. 공식 자료·판본별 개발자 기록·공식 화면을 확인했다. 이 문서는 직접 게임을 플레이한 보고서가 아니다.

## 확인 범위

- 대항해시대 4 HD: 공식 Web 매뉴얼 14개 출처, 기능 관찰 12건, 공식 UI 이미지 4개 실제 확인.
- 더 길드 3: 공식 홈페이지와 개발자 문서, 기능·화면 관찰 12건, 공식 스크린샷 19장 실제 확인.
- 더 길드 3의 일부 기능 문서는 2018·2021 Early Access 판본이다. 최신판에서 직접 실행한 결과로 취급하지 않는다.
- 영상은 공식 YouTube 링크와 Steam 트레일러 정보를 확보했으나 프레임·음성·전사 검토에 성공하지 못했다. 영상 시청 근거는 없다.
- 공식 홈페이지의 Download Manuals는 별도 카드게임 영역이므로 PC게임 매뉴얼로 사용하지 않았다.

## 인터페이스에 채택할 것

세계 전략은 지도·항로·도시·거래의 전환, 현장 운영은 사업장·직원 Task·인물의 맥락 행동으로 나눈다. 세계지도에서 회사를 움직이고, 본사에서는 일이 진행되는 모습을 확인하며, 도시에서는 사람과 장소를 경험한다. 화면 상태의 소유자는 같은 시뮬레이션 엔진이다.

원작의 가문·세습·전투·도시 독점 수익이나 직접 클릭을 많이 해야 생산성이 오르는 규칙은 초기 모델에 넣지 않는다. 필요한 경제 정보는 누구나 확인하고, 직원 전문성은 업무 처리와 조사에 반영한다.

## 재사용 범위

패키지에는 외부 게임의 이미지·영상·음원 원본을 포함하지 않는다. 자체 문장으로 작성한 관찰·설계 해석과 원문 링크를 제공한다. 실제 화면 외형은 별도 제작한다.
