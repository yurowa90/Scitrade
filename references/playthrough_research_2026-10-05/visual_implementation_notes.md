# Scitrade 직원 화면 구현 검토안

작성일: 2026-10-05. 이 문서는 공식 정지 화면 관찰을 바탕으로 새로 제안하는 구현·아트 사양이다. 기존 기획의 확정 사항이나 원작의 내부 구현을 설명하지 않는다. 수치 균형과 실제 경영 효과를 입증한 자료가 아니다.

관찰 근거는 [visual_review.json](visual_review.json)의 `sources[].id`를 참조한다. 원작 이미지 재사용 없이 화면의 정보 구조와 기능 관계를 참고한다.

## 직원 한 명을 위한 그래픽 자산 목록 제안

아래는 제작 범위를 논의하기 위한 초안이다. 기존 캐릭터 수·제작 공정·3D 도입 여부를 확정하는 목록이 아니다. 카드 프레임, 직무·속성 아이콘은 직원마다 새로 그리기보다 공통 자산으로 관리한다.

| 구분 | 제안 자산 | 연결할 용도 | 제작 주의 |
|---|---|---|---|
| 기본 원화 | 투명 배경 전신 기본 포즈, 축소 실루엣 확인용 표현 | 수집 카드·직원 소개 | 귀·뿔·꼬리가 카드 밖으로 잘리지 않는 안전 영역 설정. 종의 특징과 업무 소품을 구분 |
| 초상 | 기본 전신과 일치하는 얼굴 중심 초상, 작은 목록용 초상 | 카드·부서표·대화·알림 | 자동 자르기만으로 얼굴이 작아지는 경우 별도 구도 조정. 독립 인물처럼 보이지 않게 형태 통일 |
| 표정 | 기본·집중·기쁨·피로·걱정의 표현 초안 | 업무 상태·대화·성과 | 표정만으로 업무의 가능/불가를 표시하지 않음. 감정과 능력치를 자동으로 동일시하지 않음 |
| 업무 표현 | 대표 직무 포즈 또는 짧은 반복 동작, 협의·휴식·교육 표현 | 본사 공간·계약팀 보기 | MVP는 정지 포즈 교체로 검증 가능. 동작 길이는 경제 계산의 시간 단위가 아님 |
| 소품 레이어 | 대표 직무 도구, 선택적 회사 소속 표식 | 직무 식별·성장 외형 | 자격 배지와 장식 액세서리를 구별. 국기만으로 언어·전문성·신뢰를 대체하지 않음 |
| 성장 표현 | 기존 외형을 유지하는 숙련·전문화 강조 변형 | 교육 완료·전문화 선택 | 희귀도 상승이나 체형 변화가 반드시 필요한 것으로 가정하지 않음. 변화의 의미를 텍스트로 함께 제공 |
| 표시 기준 | 앞/뒤 배치 순서, 기준점, 카드 안전 영역, 축소 시 최소 식별 요소 | UI 통합·이미지 교체 | 같은 직원의 모든 표현을 같은 자산 키에 연결. 배경과 프레임은 캐릭터 이미지에 합치지 않음 |
| 공통 자산 참조 | 속성 문양, 직무 배지, 상태 아이콘, 카드 프레임, 선택 표시 | 전체 직원 공통 | 직원별 복제 대신 참조 사용. 색상과 도형·이름을 함께 사용 |

필요한 최소 자산 메타데이터 제안: 직원의 아트 키, 표현 이름, 파일 경로, 화면별 잘림 기준, 기준점, 배경 투명 여부, 제작 버전, 제작자·권리 출처. 능력이나 급여 같은 경영 데이터는 이미지 파일명과 색상에서 역산하지 않는다.

## 최소 검수조건

- **데이터 일치:** 같은 직원을 카드·부서표·프로젝트 화면에서 열었을 때 이름·능력·직무 자격·가용 상태가 일치한다. 교육 완료나 배정 변경이 열린 다른 화면에도 반영된다.
- **미리보기 무변경:** 후보 비교·성장 미리보기를 열고 취소해도 자금·경험·배정 상태가 바뀌지 않는다. 확정 결과와 미리보기의 차이가 생겼다면 변경된 조건을 설명한다.
- **배정 충돌 처리:** 교육 중이거나 다른 업무에 예약된 직원을 배정할 때 가능 여부와 기존 업무의 영향을 제시한다. 소속 부서를 바꾸는 일과 계약팀 배정을 혼동하지 않는다.
- **시각적 의미 구분:** 종족·속성·직무·지역 경험·희귀도·일시적 상태를 범례로 각각 설명할 수 있다. 동일한 색 하나만으로 상충하는 의미를 전달하지 않는다.
- **축소 가독성:** 실제 목표 화면 크기에서 이름·주요 수치·확정 버튼이 읽히고, 작은 초상에서도 종의 실루엣이 구분된다. 큰 귀·뿔·꼬리와 장식이 글자를 덮지 않는다.
- **비색상 표현:** 흑백 상태나 색 구분이 어려운 조건에서도 상태 이름·아이콘·기호로 판단할 수 있다. 실제 대비 수치는 구현 화면으로 별도 측정하며 이번 참고 이미지 분석이 접근성 검증을 대신하지 않는다.
- **정보 밀도:** 거래·채용·교육의 확정 전 비용·기한·변경 대상을 같은 화면에서 찾을 수 있다. 긴 설명이나 장식이 핵심 비교 수치와 버튼을 가리지 않는다.
- **연출 독립성:** 애니메이션을 끄거나 회사 장면을 닫아도 저장·재개·배정·교육 결과가 동일하게 유지된다. 업무 중·교육 중·휴식 중이라는 표식이 실제 상태와 일치한다.
- **권리·출처:** 참고 게임 이미지나 캐릭터 디자인을 제품 자산으로 포함하지 않는다. 새 자산의 제작 출처와 사용 범위를 기록한다.

검수는 예쁜 화면 한 장의 승인으로 끝내지 않고, 같은 직원의 채용 후보 확인 → 채용 → 부서 소속 → 프로젝트 배정 → 교육 예약 또는 취소 → 성장 결과 확인을 한 번 이어서 점검한다. 이 흐름은 실제 업무·학습 효과에 관한 실증 실험이 아니라 UI와 상태 연결을 검증하기 위한 시나리오다.
