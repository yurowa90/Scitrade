- [진행 중인 PR #1](https://github.com/yurowa90/Scitrade/pull/1)과 해당 브랜치의 STATUS에는 M1·M2a 첫 단계 구현 및 검증 기록이 있다. 이 문서를 추가하면서 엔진 테스트나 화면 확인을 다시 수행한 것은 아니다. `main`에 구현 PR을 병합한 것도 아니다.

## 해석할 때 유지할 구분

- 표본: 게임별 플레이·공략 5편씩 총25편, 보충 리뷰1편. 자동자막 근거 구간134개, 공식 정지 이미지17장. 영상 프레임·음성 직접 확인은 없다.
- `proposed_not_implemented`는 **이 연구 작업에서 구현하지 않은 제안**이라는 뜻이다. 최신 저장소의 기능 미구현 판정이 아니다.
- M1·M2a·M2b·P1·P2 표기는 연구와 기존 계획을 연결하는 대응표다. 단계 재시작·범위 확대·새 수치 채택의 명령이 아니다.
- 자동 처리는 통합 JSON의 `sources[].id`, `observations[].id`를 기준으로 한다. 게임별 JSON의 `videos[].id`는 YouTube ID이며 게임별 독해 기록의 필드는 서로 다를 수 있다.
- 관찰한 발화, 공식 정지 화면 관찰, Scitrade 설계 제안, 미확인 사항을 구분한다. 영상의 금액·보너스를 실증 계수로 채택하지 않는다.
- 자동자막·정지 이미지 분석을 실제 영상 시청, 원작 소스 코드 분석, 최신 버전 재현 검증으로 표현하지 않는다.

## 다음 작업에 적용하는 방법

현재 진행 중인 기능에 관련된 REF 항목을 고른 뒤 근거 → 기존 코드와의 차이 → 변경할 사용자 행동 → 완료 조건 순서로 기록한다. 현재 구현을 보존하면서 필요한 항목만 단계적으로 적용한다. 이 연구 자체는 경제 규칙이나 사용자 승인된 사양을 바꾸지 않는다.

예를 들어 동료 발견·면담·영입·고용을 작업 중이라면 REF-01·05·12부터 확인한다. 도감 발견과 고용 상태를 구분하고, 같은 직원의 카드·비교표·계약 배치에서 상태가 일치하는지 검사한다. 레벨·교육은 REF-04·06·07, 위임은 REF-09·10과 연결한다.

## 포함 범위와 검증

- 기존 배포 묶음의 문서·JSON·CSV 15개와 이 인계 문서를 제공한다. ZIP 대신 압축 해제된 파일을 Git에서 읽고 검색할 수 있다.
- 원작 영상·자막 전문·공식 이미지 원본은 포함하지 않는다. 출처 URL과 자체 요약·설계 제안이 자료다.
- `MANIFEST.json`의 파일 해시는 GitHub판 README 보완과 이 인계 문서 추가를 반영한다. 저장소 루트의 MANIFEST에도 이 폴더를 포함한다.
- 확인 범위는 자료 파일, JSON 참조·시간 범위, 해시, 상대 링크와 기존 데이터 검증이다. 게임 코드·경제 계수·실제 아트 제작은 이번 업로드의 변경 대상이 아니다.
