# 그림·모션 제작 목록 (일괄 제작용)

사용자 결정 (2026-10-04): 개발 중에는 카드 자리표시자와 코드로 그린 임시 표현으로 진행한다. 그림·모션 디자인은 마지막에 한꺼번에 만든 뒤 교체한다.

운영 규칙:
- 그림이나 움직임이 필요한 기능을 만들 때마다 이 목록에 항목을 추가한다. 코드에는 교체 가능한 자리표시자를 넣는다.
- 그림은 `src/assets/manifest.json`에 `approved`로 등록해야 화면에 쓰인다. 등록 전까지 자리표시자가 유지된다.
- 제작 방법·프롬프트·점검표는 [PROMPTS.md](PROMPTS.md), 미술 방향은 [../ART_DIRECTION.md](../ART_DIRECTION.md)를 따른다.
- **2026-10-05 사용자 결정으로 모든 그림·지도는 픽셀아트다.** 크기·팔레트·형식은 [PIXEL_SPEC.md](PIXEL_SPEC.md)가 기준이고, 아래 규격 칸도 그에 맞췄다.
- 모든 모션은 ‘움직임 줄이기’ 설정에서 꺼지고 같은 정보를 글자로 보여 줘야 한다.

상태: `임시`(코드로 그린 대체물 사용 중), `미제작`(자리 없음, 해당 단계에서 추가), `완료`.
