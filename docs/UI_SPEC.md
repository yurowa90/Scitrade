# 인터페이스 명세 — 세계 전략과 현장 경영

이 문서는 프로젝트 설계다. 레퍼런스에서 직접 확인한 사실은 `references/`에 별도로 기록한다.

## 전체 구성

기준 화면은 데스크톱 1440×900, 최소 검토 화면 1280×720으로 제안한다. 화면 축소 시 중요한 계약 금액·기한·승인 버튼이 가려지지 않게 우선순위를 정한다. 모바일 완전 대응은 초기 완료 조건이 아니다.

| 영역 | 표현 | 주의 |
|---|---|---|
| 상단 | 회사·일자·정지/진행·현금·임박 지급 | 현금과 이익은 다른 라벨. 진행 버튼은 작업 중 비활성 |
| 왼쪽 | 세계지도 / 회사 / 도시 / 거래 / 보고 | 같은 상태를 다른 관점에서 접근. 도시마다 별도 회사 현금 생성 금지 |
| 중앙 | 선택 화면의 지도·사업장·장소 | 시각적 중심. 표가 필요할 때 계약·운송 비교 패널로 전환 |
| 오른쪽 | 선택한 화물·직원·인물·계약 정보 | 조건·근거·행동을 한 맥락에서 표시 |
| 하단 | 업무 대기·사건·새 연락·기한 | 변경된 항목만 강조. 정보 없는 매일 방문 요구를 만들지 않음 |

## 레퍼런스의 결합 방식

- 세계·도시·거래를 오가는 구조에서 대항해시대 4의 읽기 쉬운 정보 전환을 참고한다.
- 본사에서는 더 길드 3처럼 직원과 시설의 작업이 보이게 하되, 표시된 애니메이션이 엔진 시간을 결정하지 않는다.
- 장소를 누르면 인물 초상·맥락 대화·현재 선택이 나타난다. 주변 도시 장면을 유지해 공간 맥락을 살린다.
- 화면 장식보다 가격·기한·담당자·다음 행동을 우선한다. 원작의 텍스처·프레임·초상화는 재사용하지 않는다.

## 문화와 관계의 표현

국가별 기록장 안에 도시·주제 카드를 둔다. ‘지역 이해’는 발견한 정보, ‘친밀’은 특정 인물과 함께한 경험, ‘거래 신뢰’는 이행 기록으로 나타낸다. 막대 하나만 보여주기보다 새로 알게 된 사실·지킨 약속·새로 열린 질문을 함께 보여준다. 회사 보고서와 직원 개인 경험은 소유 범위가 다르다.

예시: 시장 상인의 포장 요구→추가 인터뷰→관련 고객의 주문 조건 확인→기존 소포장 규격 견적. 활동 완료 화면에서 경험·알게 된 점·관련 인물·후속 행동을 짧게 제시한다. 다른 나라 전체의 선호라고 표현하지 않는다.

## 빈 상태·실패·접근성

- 현금·업무량·위치 부족은 행동 옆에 이유와 필요한 조건을 보여준다.
- 조사 전에는 ‘미확인’, 검사 전에는 ‘검사 대기’로 표시하고 0위험·불합격으로 바꾸지 않는다.
- 정보의 오래됨, 예측과 관측, 입력 오류를 색상만으로 구분하지 않는다.
- 키보드 탐색·명확한 포커스·툴팁의 텍스트 접근을 고려한다.
- 장소를 닫아도 주문·Task 상태가 사라지지 않는다. 실수로 실행한 중요 경제 명령의 결과와 취소 조건을 보여준다.

## 화면 제작 첫 순서

M1에서는 UI_TRADE·간단한 UI_WORLD·UI_REPORT만 만든다. 이후 UI_COMPANY·UI_CITY·UI_CONTACT·UI_CULTURE를 연결한다. 기본 상태와 거래가 동작한 뒤 분위기 그림과 애니메이션을 추가한다.
