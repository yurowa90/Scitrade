**바뀌지 않는 것**
- 글자: 이름·수치·설명·지도 이름표는 일반 글꼴(IBM Plex Sans KR, Gowun Dodum)로 쓴다. 한글 픽셀 글꼴은 작은 크기에서 읽기 어렵고, 이 게임은 수치를 읽고 판단하는 학습 도구다. 제목·로고에 픽셀 글꼴(예: 갈무리, SIL OFL 1.1)을 쓸지는 그림 제작 때 정한다.
- 색만으로 뜻을 전하지 않는다. 속성·직무·상태는 모양과 글자를 함께 쓴다.
- ‘움직임 줄이기’ 설정에서는 스프라이트 움직임·광택·기울기를 끄고 같은 정보를 글자로 보여 준다.
- 가져오지 않는 것(한정 일련번호, 판매·방생, 전투 능력치, 원작의 이름·실루엣·장식)은 그대로다.

**주의할 점 (비판적 검토)**
- **종 구별:** 32×32에서는 비슷한 종(두루미와 다른 물새 등)을 구별하기 어렵다. 종의 정확한 특징(멸종위기종 주의사항 포함)은 카드 그림이 맡고, 스프라이트는 색과 특징 1~2개로 알아보게 한다.
- **믹셀:** 한 화면에서 픽셀 크기가 서로 다르면 픽셀아트의 일관성이 깨진다. 그래서 같은 장면의 그림은 같은 배율로 보인다. 개발 중 벡터 자리표시자가 픽셀 지도 위에 섞이는 것은 임시 상태로 기록한다.
  - 지금 알려진 어긋남: 지도 픽셀은 3 CSS px에서 멈추지만, 벡터 이름표·휘장은 틀 폭 946 CSS px 기준까지 커진다(2026-10-06, `art/PIXEL_SPEC.md` 6절). 거점·배 그림을 픽셀로 바꿀 때 함께 맞춘다.
- **학습 효과:** 픽셀아트 자체가 학습을 돕는다는 근거는 찾지 못했다. 이 전환은 제작 일관성·파일 크기·사람의 편집 가능성을 위한 선택이다. 판단 화면의 장식 최소화 원칙(유혹적 세부 효과)은 그대로 지킨다.

## 미술 지침

- 대략 2.5~3등신의 동물·신수. 둥근 외곽, 읽기 쉬운 얼굴, 큰 특징 1~2개와 업무 소품 1개.
- ~~기본은 부드러운 셀풍 2D 일러스트와 작은 스프라이트.~~ (2026-10-05 픽셀아트로 대체, 맨 위 절) 사무실은 단순한 아이소메트릭 장면으로 구성한다.
- 선택된 카드만 기울기·레이어 시차·빛 효과를 적용해 입체감을 준다. 모든 카드에 실시간 3D 모델을 요구하지 않는다.
- 기본 배경은 크림·연한 민트·하늘색. 경영 수치와 본문은 네이비 계열로 충분한 대비를 확보한다. 각 색의 실제 코드와 대비 검증은 UI 제작 단계에서 고정한다.
- 속성은 색+형태 아이콘+문자로 표시한다. 희귀도, 직무, 지역 경험의 모양과 위치를 분리한다.
- 조직 화면은 부서별 열, 팀별 묶음, 직원 카드로 구성한다. 프로젝트 편성은 별도 최대3슬롯 영역으로 보여준다.
- 카드 상단: 이름·속성·직무. 중앙: 일러스트. 하단: 레벨·강화·현재 일정·핵심 능력. 전체6능력은 상세에서 펼친다.
- 국가 표시는 국적 능력 배율 대신 경험한 지역 배지·여행 수첩 링크다. 긴급 지급·납기 표시를 카드 반짝임보다 우선한다.
- 움직임 줄이기 설정에서는 반짝임·기울기·폭죽을 끄고 동일한 정보와 완료 결과를 텍스트로 제공한다.
- **문서 충돌 기록 (2026-10-09, 결정 대기):** 이 문서의 ‘선택 카드 광택’(:19 표, :56, :77)과 `UI_SPEC.md` ‘v0.4 수집·육성·조직 화면’의 ‘영입과 중요한 성장 순간에만 카드 반짝임’이 부딪친다. 지금 코드는 이 문서를 따른다(선택 카드에 계속 도는 광택 `src/ui/style.css:185-192`, 움직임 줄이기에서 끔 `:222-225`). 기준은 그림·모션 일괄 제작(M5) 전에 정한다. 자세한 기록은 UI_SPEC 같은 절.

## 제작 방식과 세계지도 — 2026-10-04

**제작 시점 (사용자 결정, 2026-10-04):** 개발 중에는 카드 자리표시자와 코드로 그린 임시 표현으로 진행하고, 그림·모션 디자인은 마지막에 한꺼번에 만들어 교체한다. 필요한 항목은 [art/ASSET_BACKLOG.md](art/ASSET_BACKLOG.md)에 기능을 만들 때마다 쌓는다.

**제작 방식 (사용자 결정):** 동료와 배경 그림은 사람 일러스트 외주 없이 생성형 AI(미드저니 등)로 만든다. 일관성 유지 절차, 프롬프트, 점검표, 출처 기록은 [art/PROMPTS.md](art/PROMPTS.md)를 따른다. 채택한 그림은 `src/assets/manifest.json`에 출처와 함께 등록해야 화면에 쓰인다.

**세계지도 (사용자 요청: 위성사진 느낌, 대항해시대·더 길드 3 수준의 게임 그래픽):** M1의 단순 개념 지도를 다음과 같이 바꿨다. *(2026-10-06: 위성 영상 지도는 픽셀 지도로 대체되었다. 지금 기준은 [art/PIXEL_SPEC.md](art/PIXEL_SPEC.md) 6절이다. 아래는 기록으로 남긴다.)*
- 배경: 공공 도메인 위성 합성 영상(NASA Blue Marble)과 지형 높이 지도를 동아시아 해역(98~146°E, 10°S~44°N)으로 잘라 `scripts/build_map.py`로 가공. 산맥 음영, 수심 느낌의 바다 그라데이션, 모래색 해안선, 가장자리 어둡게 처리.
- 표시: 항구 닻 휘장과 이름 리본, 흐르는 점선 항로, 컨테이너 화물선, 하역 중단 폭풍 표시, 나침반, 5° 경위선. ‘이번 항로’와 ‘전체 해역’ 보기를 바꿀 수 있다.
- 한계: 영상 사본은 제3자 저장소에서 받았고 NASA 원본과 대조하지 않았다(작업 환경에서 NASA 서버 차단). 항구 좌표는 0.1° 근사이며 항로선은 표시용이다. 운송시간·거리는 지도와 무관하게 `routes.json`의 값만 쓴다.

| 구도 | 캐릭터 중심, 위아래 약 15%는 이름·레벨·속성 표시가 덮을 수 있게 비움 | 전신, 가운데 |
| 빛·입체감 | 그림에는 넣지 않음. 홀로그램 광택·기울기는 코드 효과(선택한 카드만) | 없음 |

배경 무늬 예: 두루미는 설원과 갈대, 고래상어는 별빛 같은 바다, 해치는 궁궐 단청에서 영감을 받은 문양, 곤붕은 구름과 파도가 이어지는 하늘. 실재 건축물·문화재 도안을 그대로 옮기지 않는다.

계속 제외하는 것: 한정 일련번호, 판매·방생, 전투 능력치(공격·방어·생명력), 종합 전투력처럼 읽히는 숫자 배지, 원작의 프레임 장식·배지 모양·이름. 카드 테두리는 금빛 덩굴 등 자체 디자인으로 코드에서 그린다.
