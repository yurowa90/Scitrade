# 자료 묶음 검증 기록 — v0.4

확인일: 2026-10-04. 대상: 코드 세션 시작 자료.

## 수행 결과

- 데이터 JSON 23개와 대응 스키마, ID·출처·교육과정 참조를 검사했다.
- 기존 M1 정상·취소·지연 거래의 현금·재고·채권 산술을 검산했다. 캐릭터 시스템이 M1에서 비활성인지 확인했다.
- 캐릭터12종의 능력 합계·속성·희소성·직원ID·표시 이름과, 3부서·7팀·직무6종의 연결을 검사했다.
- 레벨 경험치 문턱, 강화 누적70만원·10일·능력+15와 최종100상한, 시너지10%상한·시설처리량 제한의 기준 산술을 검산했다.
- 기존14개와 캐릭터·성장·조직8개, 총22개 인수 명세의 ID와 개수를 확인했다.
- ECB 표본10행의 교차환율, 원자료 추출 기록, 전체 설계 문서 해시와 배포 파일 해시를 확인했다.

실행: `python3 tools/validate_data.py`. 최종 묶음에서 PASS 확인. ZIP의 압축 오류 검사도 통과했다.

## 결과의 범위

게임 엔진과 화면은 아직 없다. 위 결과는 구조·참조·기준 산술 검사이며 22개 게임 테스트를 실행해 통과했다는 뜻이 아니다. 미술 파일·애니메이션·경제 보정·교육 효과·실제 플레이 검증은 남아 있다. 스키마는 시작 데이터의 구조이며 최종 명령 API를 대신하지 않는다.

이전 레퍼런스 조사: 대항해시대4 공식 매뉴얼 화면4개, 더 길드3 공식 스크린샷19개와 관련 문서, 관찰24건. 두 게임의 공식 영상은 실제 프레임 확인에 실패했다.

이번 사용자 영상: 1000026376.mp4 약13.02초의 광고에서 1초 간격13개 정지 프레임을 확인했다. 둥근 캐릭터·도감·큰 카드·빛 효과·능력 표시의 시각 표현만 근거로 삼았다. 음성·조작·확률·과금·출시판 기능·실제3D구현은 검증하지 않았다. 원본 영상과 추출 프레임은 배포하지 않는다.

## 이후 변경 — 2026-10-04

- 인수 명세가 25개가 되었다. 거래·운영 17개(P0-M2A-01~03 추가)와 캐릭터·조직 8개다.
- `tools/validate_data.py`에 M2 시나리오(`SCENARIO_M2_MULTI_TRADE`) 검사를 추가했다. 경로별 현금·예약·매출·원가·기여이익 산술, 출항편 공간, 거절 사례, 인수 명세와 시나리오 기대값의 일치를 본다.
- 엔진 테스트는 `npm test`로 따로 실행한다. 결과는 `docs/STATUS.md`에 기록한다.

교육과정은 2022-33 최초 확정 고시 기준의 기존 대조 기록을 유지한다. 후속 개정 전체 대조와 성취기준 코드 매핑은 포함하지 않았다.
