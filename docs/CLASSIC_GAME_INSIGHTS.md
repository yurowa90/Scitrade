# 고전게임 인사이트의 Scitrade 적용

작성: 2026-10-08 KST. 비교 기준: PR #1 개발 head `8590193ce895654def50b34e7226499e880e1058`.

**반영 수준: 기획 보완과 단계별 검증 기준. 게임 코드·경제 규칙·수치·저장 판본의 구현 변경은 아니다.** 사용자의 고전게임 인사이트 반영 요청에 따라 기존 계획에 연결했다. 엔진·화면 구현 상태는 [STATUS](STATUS.md)가 기준이며, 아래 제안의 존재를 구현 완료로 읽지 않는다.

## 1. 지켜야 할 게임 목적

Scitrade는 동물·신수 동료를 만나고 함께 성장하며, 도시·문화·사람을 알아가고, 현대 무역회사를 경영하는 게임이다. 플레이어는 돈·시간·인력·지역 환경을 함께 고려해 선택하고 결과를 되짚는다. 사회·과학은 그 판단의 근거에 들어가며 교과 퀴즈가 진행의 관문이 되지 않는다.

- 경영의 재미: 제한된 자원을 어디에 쓰고 어떤 기회를 보류할지 판단한다.
- 동료의 재미: 능률뿐 아니라 함께 겪은 일·개성·인연을 기억하고 다음 경험을 기대한다.
- 세계의 재미: 지역 지식·인물 친밀·거래 신뢰를 구분하고, 사업 보상이 없어도 문화·풍경·사연을 발견할 수 있다.
- 학습의 경험: 자료를 읽고 대안을 비교하며, 무엇을 바꾸었기에 결과가 달라졌는지 설명한다.

기준 작품은 대항해시대 **4**의 세계 교역망과 더 길드 3의 사업장·인물 운영이다. 이번 자료는 에어 매니지먼트 2·캐피탈리즘 2·베스트 라이브러리 리런 등을 판단 구조별로 더한다. 여러 게임의 모든 기능을 합친다는 뜻은 아니다.

## 4. 먼저 만들 경험: 한 번의 경영 순환

다음은 후속 구현을 위한 **합성 장면 제안**이며 현재 게임에 추가된 사건이 아니다. 실제 경제 값과 보상은 기존 규칙을 쓰고, 새 수치는 별도 검산·규칙 결정 전에 확정하지 않는다.

1. **관심을 만든다.** 동료가 새 거래 기회와 도시에서 알아보고 싶은 이야기를 함께 전한다. 문화 활동은 수주를 위한 의무가 아니다.
2. **병목을 찾는다.** 두 일감을 동시에 준비할 때 필요한 시간과 직원의 가용 시간을 비교한다. 여유가 있으면 고용을 요구하지 않는다.
3. **다르게 선택한다.** 기존 직원을 재배치하거나, 고용을 검토하거나, 일감을 보류한다. 훈련·탐방에 보낼 때 생기는 당일 공백을 함께 본다. 미구현인 대체편·협상은 활성 선택지로 제시하지 않는다.
4. **결과를 본다.** 계약 진행·현금·급여·동료 경험·문화 기록을 각자의 의미로 보여 준다. 거래 수익과 관계·발견을 하나의 점수로 합치지 않는다.
5. **다음 목적을 만든다.** 회사의 다음 투자와 별도로 동료와 다시 가고 싶은 장소·남은 질문을 남긴다.

```mermaid
flowchart LR
    A["동료·도시에서 관심 발견"] --> B["보고와 자원에서 제약 파악"]
    B --> C["수주·배치·성장·탐방 선택"]
    C --> D["경영 결과와 동료·문화 경험"]
    D --> E["설명·재계획·다음 만남"]
    E --> A
```

## 5. 적용 순서와 범위

### 기존 화면·콘텐츠를 보강할 때

- CL-01~03: 새 회계·예약 엔진 대신 기존 보고·계약 진행·자원 예약 데이터를 연결한다. 오늘 판단에 필요한 요약에서 세부 근거와 행동으로 이동한다.
- CL-05·07: TASK-0012 문화 화면에 이미 정해진 네 줄 기록과 직원별 경험을 읽기 쉽게 연결한다. P0의 부산 3활동·1일·업무 공백·중복 보상 금지는 유지한다. 새 도시 이동이나 후속 견적을 이 단계에 넣지 않는다.
- 가로 기기의 좁은 상세 영역, 오늘 할 일 위치, 키보드 순서는 실제 후속 화면 검토 대상이다. 모든 관리 정보를 첫 화면에 늘어놓지 않는다.

### 기존 M2a-4b·M2a-5·M2b에서

- M2a-4b: 문화 기록과 재방문·인물 이야기·후속 기회를 연결하되, 문화 활동을 해야만 핵심 거래 정보를 얻도록 잠그지 않는다.
- M2a-5: 창고 보관 용량과 하루 처리량, 수요와 이용률, 현재 투자와 지속 비용을 구분한다. 시설 확대·채용이 불필요한 상황도 유효한 판단 사례에 포함한다.
- M2b: 직원 성장·직무·팀이 실제 업무의 선택을 바꾸는지 확인한다. 기존 업무별 시너지 상한과 물리 용량·가격·관세·선박 속도 불변 조건을 유지한다.

### M3·M5 및 이후

- CL-04·08: 전문화/다변화, 예고된 사건에 대한 준비, 예상과 결과의 차이를 기존 사건과 경쟁 구조 안에서 검증한다.
