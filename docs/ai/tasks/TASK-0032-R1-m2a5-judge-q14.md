## 구현 지시

### 1. J4 상한(Q14 가) — `src/engine/sim/d03.ts`

- 상한 `1910000`(19,100 USD, 시작 분석값 10,600의 1.8배)을 `2120000`(21,200 USD, 2.0배)으로 바꾼다. 하한 `1060000`은 그대로 둔다.
- 두 값을 이름 있는 상수로 둔다. 예: `J4_NET_MIN_MINOR = 1060000`, `J4_NET_MAX_MINOR = 2120000`. 주석에 근거를 한 줄로 적는다. ‘모형 판정 4의 개연성 점검. 상한은 Q14(2026-10-13)에서 시작 분석값의 1.8배 → 2.0배로 다시 정함’.
- J4 근거 문장 끝에 **상한 대비 여유**를 더한다: `; 상한 21,200까지 여유 {(상한 − 중앙)/상한 × 100, 소수 첫째 자리}%`. 중앙이 상한을 넘으면 음수로 적는다. 판정식은 바꾸지 않는다.
- J4 줄의 판정 이름 옆이나 표 설명 문장에 ‘개연성 점검’이라는 성격을 한 번 밝힌다. 예: ‘J4(개연성 점검: 묶음 견적 수·준비 pt·환전 없이 실패·기준 순자산 범위)’.

### 2. 감액 변형의 J2를 진단으로(Q14 나) — `src/engine/sim/d03.ts`

- `mode !== 'base'`이면 J2 판정 값을 `null`로 둔다. 표에는 ‘진단’으로 나오게 하고, 근거 문장은 지금처럼 정책별 `↑·↓` 개수를 그대로 적는다.
  - 지금 ‘해당 없음’으로 나오는 다른 판정(J2b·J3·J5)과 구분되게 표시한다. 판정 칸 글자는 ‘진단(Q14)’으로 하고, 근거 문장 앞에 ‘감액 변형은 비교용 규칙이라 판정하지 않음 — ’을 붙인다. 표시 방법이 지금 `judge` 함수로 어렵다면 가장 작은 변경으로 하고, 방법을 ‘설계 판단’에 적는다.
- 기준 규칙(`base`)의 J2 판정식은 그대로 둔다.
- 표본 밖 실행(`--seed-base`)의 J2b는 코드에서 따로 처리하지 않는다. 결과 보고에서 ‘기록만, 판정 아님’으로 적는다.

### 3. 실패 시험: 차단 예측 시험의 시장 조건 고정 — `src/engine/m2a5-warehouse.test.ts`, `tests/acceptance_cases.json`

- 대상: `M2a-5 차단 기간 예측` › ‘23일의 12pt 대기 업무를 차단될 직원에게 맡기지 않고 실제 완료일까지 예측한다’.
- 원인(1차 질문 절): 시험이 정책 실행을 23일까지 돌려 상황을 만든다. 그런데 새 시장 값에서는 23일 강제 수락이 자금 부족으로 거절된다. 시험의 의도는 차단 기간 예측이지 시장 가격이 아니다.
- 고침:
  - TASK-0030 시점의 시장 조건(`max_lots_choices` `[1, 2, 3]`과 판매 행 4개의 기준가 14.00·49.00·13.50·50.00 USD)을 **인수 명세 자료**에 둔다. 위치는 `tests/acceptance_cases.json`에서 이 시험과 가장 가까운 사례(`P0-M2A5-04` 준비 예측 사례)의 `test_fixture`, 새 칸 `blocked_repro_market`이다.
  - 판매 행은 `{ city_id, good_id, side, base_price_minor }` 목록처럼 자료 ID로 식별한다. 자료 ID는 JSON에 둔다.
  - 시험은 `structuredClone(config)`로 사본을 만들고, 이 고정 조건을 사본에 덮어쓴 뒤 지금처럼 진행한다. 시험 소스에는 가격 숫자와 자료 ID를 쓰지 않는다(TASK-0027 R1 규칙).
  - 시험의 단언은 바꾸지 않는다. 고정 조건을 덮어쓴 사본에서 1차 전(TASK-0030) 기대값 그대로 통과해야 한다.
- 변형 1: 고정 조건 덮어쓰기를 뺀다 → 이 시험이 실패해야 한다.

### 4. 표 다시 만들기

- 1차 측정 JSON 4개(기준·cap30·flat200·표본 밖)를 `d03 --tables-from`으로 다시 표로 만든다. `docs/ai/tasks/results/TASK-0032-d03*.md`를 갱신한다. 1차 JSON이 작업 공간에 없으면, 같은 명령으로 기준 조건만 다시 재고 그 사실을 적는다.
  - 기대: 기준·표본 밖 J4는 통과(여유 약 2.0%·1.2%)다. cap30·flat200의 J4도 같은 값으로 통과하고, J2는 진단이다.
