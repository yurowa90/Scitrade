## 구현 지시

### 꼭 고칠 것 (MF)

**MF-1. 오늘 할 일에 넣는 버튼: 화면 튐 막기, 누른 자리에서 확인, 두 번 누름 막기.**
- a) 초점 복원은 `focus({ preventScroll: true })`로 한다.
  - 포인터로 누른 경우(`click`의 `ev.detail > 0`)에는 `#queue-h`로 대체하지 않는다.
  - 키보드로 누른 경우(`detail === 0`)에도 초점이 몸체(`body`)로 사라지지 않게 가까운 대상으로 옮긴다. 그 대상의 가운데가 고정 막대 밑에 있으면 안 된다.
- b) 견적 수락(`accept`, `accept-fwd`, `accept-plan`)이 대기 목록에 들어가면, 새로 생길 계약 카드의 제목을 고정 막대 바로 아래로 가져온다.
  - 계약 카드 제목에 `id="contract-h-<계약ID>" tabindex="-1"`을 단다. 대기 중인 계획 계약도 화면에 카드가 있으면 그 ID를 쓴다.
  - 배정·예약·조사·의뢰·고용·훈련은 스크롤 위치를 바꾸지 않는다. 같은 자리에서 상태 표시가 버튼을 대신한다.
- c) 확인 문구(`ui.flash`)를 누른 자리에서 보이게 한다. 둘 중 하나로 한다.
  - 대상 카드 안에 같은 문구를 보인다.
  - 화면 아래쪽 고정 알림(`role="status"`)으로 보인다.
  - 오늘 할 일 패널의 기존 문구는 그대로 둔다.
- d) `html { scroll-padding-top: var(--topbar-h) }`를 두고, `--topbar-h`는 고정되는 부분의 실제 높이로 갱신한다(`ResizeObserver`).
- e) `queue()`·`endDay()`가 다시 그린 직후 약 500ms 동안은 `[data-action]` 클릭을 무시한다. 버튼에 `touch-action: manipulation`을 준다.

**MF-2. 휴대폰 세로에서 고정 막대를 줄인다.**
- 위쪽 막대를 둘로 나눈다.
  - `.masthead`(고정하지 않음): 로고, 시나리오 선택, 저장·불러오기·내보내기·가져오기·처음부터.
  - `.statusbar`(고정): 날짜와 단계, 거래 현금, 사용 가능, 운영 현금, 다음 수금, ‘하루 진행 ▶’.
- 다섯 값은 모두 남긴다. Q5·T2가 이 값을 쓴다.
- `@media (max-width: 700px)`에서는 상태 막대를 최대 3줄로 하고, 이름표를 값 옆에 작게 붙인다.
- ‘금액은 확정 기준’은 보이는 글자로 남기되 줄을 늘리지 않게 넣는다. 마우스를 올려야 보이는 `title`로 바꾸지 않는다.
- 태블릿·노트북의 고정 부분 높이는 지금보다 늘리지 않는다.

**MF-3. 한 열 배치에서 거래를 먼저.**
- `@media (max-width: 1100px)`의 순서를 바꾼다: `"trade" "queue" "crew" "resources" "report" "world" "log"`.
- 원하면 상태 막대 안에 ‘거래 / 할 일 / 동료’ 바로가기를 둔다.

## 시험

화면 시험 틀(`main-testkit`)로 다음을 확인한다.
- 포인터 클릭(`detail > 0`)으로 수락하면, 초점·스크롤 대상이 새 계약 제목이다. `#queue-h`로 대체되지 않는다.
- 배정·예약 뒤에 스크롤 요청이 없다.
- 키보드 활성화(`detail === 0`) 뒤 초점이 `body`가 아니다.
- 다시 그린 뒤 500ms 안의 두 번째 클릭은 대기 목록 수를 바꾸지 않는다. 500ms 뒤에는 바꾼다(시간은 가짜 타이머로 다룬다).
- 확인 문구가 대상 카드 안이나 고정 알림에 있다.
- 처음부터·시나리오·불러오기에서 확인을 거절하면 상태가 그대로다.
- 한 열 배치 순서는 CSS 문자열로 확인한다.
- 배정·예약 버튼은 적용될 때 `title`이 없다.
- 막힌 예약 이유가 버튼 밖 `.reason`에도 있다.
- 카드를 두 번 눌러도 선택이 유지된다.
- 문서 제목이 시나리오를 따른다.
- 기존 시험의 판단 문구 단언을 약화하지 않는다.

**브라우저 측정(Playwright Chromium).** 가능하면 직접 측정하고 보고서에 수치를 적는다. 그렇지 않으면 Claude가 측정한다.
- 기기: iPhone 13(390×664), Galaxy S24(360×780), Pixel 7, iPad Mini 세로, iPad gen 7 세로·가로, Galaxy Tab S9 세로(640×1024), 노트북 1280×800·1366×657.
- 기준:
  - 고정 부분이 iPhone 13·Galaxy S24·Pixel 7 세로에서 150px 이하.
  - 견적판 제목이 처음 화면에서 고정 부분 아래 1.0화면 이내(≤1100px 모든 기기).
  - 수락 뒤 새 계약 제목의 위쪽이 고정 부분 아래 0~60px이고, 확인 문구 한 줄 이상이 보인다.
  - 배정·예약 뒤 스크롤 변화가 40px 이하. 배정 뒤 2일 편(ROUTE02-D002) 예약 버튼이 고정 부분 아래에 온전히 보인다.
  - 초점 받은 요소의 가운데가 고정 부분 밑에 있지 않다.
  - ‘하루 진행’을 두 번 누르면 하루만 지나간다. ‘견적만 수락’을 두 번 누르면 하나만 들어간다.
