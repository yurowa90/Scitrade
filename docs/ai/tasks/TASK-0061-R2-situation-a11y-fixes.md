## 구현 지시

### 1. 결함 1(확정): 지도 안 선택 뒤 초점이 BODY로 빠짐

- 재현: 자유 탐색에서 항만 점이나 거점을 누른다.
  - `redraw(undefined)`로 대화상자 내용이 다시 그려지면서 초점이 `BODY`로 빠진다.
  - 그 뒤 Escape로 닫히지 않는다.
  - Tab 첫 이동은 토글로 간다.
  - 원인: `keydown` 처리가 대화상자 루트에만 붙어 있다.
- 고칠 것
  - 다시 그린 뒤에는 **선택한 대상의 정보 칸 제목**(`tabindex="-1"`)으로 초점을 옮긴다. 선택이 없으면 대화상자 제목으로 옮긴다.
  - Escape·Tab 순환 처리는 루트가 다시 그려져도 살아 있게 한다. 대화상자가 열린 동안에만 `document` 단위로 붙이고 닫을 때 떼거나, 다시 그려지지 않는 고정 바깥 틀에 붙인다.
  - 일반 원칙: **다시 그리기 전에 초점이 대화상자 안에 있었으면, 다시 그린 뒤에도 대화상자 안의 의미 있는 자리에 있어야 한다.**
    - 버튼을 눌러 다시 그린 경우에는 같은 `data-action`·`data-id`를 가진 버튼으로 돌려놓는다.
    - 그 버튼이 사라졌으면 위의 제목으로 옮긴다.

### 2. 결함 2: 살아 있는 영역이 매번 새 노드

- `root.innerHTML` 재생성 때문에 `#situation-live`와 브리핑 카드 `role="status"`가 매번 새 노드가 된다. 막 삽입된 live region은 많은 낭독기가 알리지 않는다.
- 고칠 것
  - 낭독용 살아 있는 영역을 **다시 그리기 밖의 고정 자식**으로 둔다. 대화상자 안에서 `inert`가 아닌 곳이다.
  - 문장만 바꿔 넣는다(`textContent`).
  - 브리핑 카드의 `role="status"`는 뺀다. 브리핑 문장은 이 고정 영역으로 한 번 알린다.
  - 같은 문장을 다시 알려야 할 때(예: 같은 레이어를 껐다 켬)는 지금 화면들이 쓰는 방식을 따른다. 결과 보고에 어느 방식인지 적는다.

### 3. 판단거리(허브 채택)

- **항만 점 누르기 판정.**
  - 점의 지름(4.8 CSS px)은 그대로 둔다. 같은 정보가 ‘표로 보기’에 있으므로 WCAG 2.5.8 예외다.
  - 누르기 판정 반지름은 **화면 기준 22 CSS px**로 넓힌다. 지금 `nearestMarks`와 같은 값이다.
  - 겹치면 지금 지도 칸처럼 ‘이 근처에 여러 곳이 있습니다’ 목록을 보인다.
- **자유 탐색 시작 영역.** 상황실을 열 때 자유 탐색은 **현재 시나리오 항로 범위**(평택–상하이–하이퐁과 진행 중 화물)를 담는 최소 영역에 여백 15%를 더한 곳에서 시작한다.
  - 지금은 1366 폭에서 1,056px 가운데 588px만 쓰고, 지도 글자가 11~14px다.
  - 동아시아 전체는 ‘전체 보기’ 단추 하나로 돌아간다. 이 단추는 새로 만든다.
- **브리핑 문단 잘림.** 104px에서 잘리는 문단을 자르지 않는다. 카드 안에서 줄바꿈해 모두 보인다.
  - 1024×768에서 토글 5개가 스크롤 없이 보이는 조건은 지킨다.
  - 둘이 부딪치면 브리핑 카드의 ‘자세히’ 펼침을 쓴다(기본은 첫 두 문장). 어느 쪽을 골랐는지 결과 보고에 적는다.

## 시험

`src/ui/situation.test.ts`에 다음을 더한다.
1. 자유 탐색에서 항만 점을 누른 뒤 `document.activeElement`가 대화상자 안이다. Escape로 닫히고 ‘상황실’ 단추로 초점이 돌아온다.
2. 레이어 토글을 두 번 바꿔도 살아 있는 영역 노드가 같다(`isSameNode`). 문장은 바뀐다.
3. 브리핑 카드에 `role="status"`가 없고, 브리핑 문장이 고정 영역으로 한 번 나간다.
4. 누르기 판정: 점에서 20px 떨어진 곳을 눌러도 그 항만이 고른다. 23px 이상이면 고르지 않는다.
5. 자유 탐색 시작 영역은 시나리오 항로 도시를 모두 포함하고 동아시아 전체보다 작다. ‘전체 보기’는 동아시아 전체로 돌아간다.
6. 긴 브리핑 문장이 잘리지 않는다. 카드 높이 고정이나 `overflow:hidden`으로 숨겨진 글자가 없다. 펼침 방식을 골랐다면 펼친 뒤 전체가 보인다.
