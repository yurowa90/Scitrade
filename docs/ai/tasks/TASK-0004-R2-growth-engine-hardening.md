## 목표

R1의 A-1~15와 B-1~5는 코드상 모두 반영되었다. 검증자들은 실제 저장 2,013개와 도달 가능한 상태 10만여 개를 다시 불러와 봤는데, 정상 저장이 거절된 경우는 없었다.

남은 것은 두 가지다.
- **약한 테스트:** 새로 만든 저장 모양 검사, 훈련 미리 보기, 급여 지급 가능일에서는 일부러 넣은 오류 여러 개가 전체 테스트를 통과했다. 테스트가 그 코드를 지키지 못한다는 뜻이다.
- **작은 설계 빈틈 셋.**

다음 화면 작업(TASK-0005)이 이 함수들에 기대므로 지금 단단히 한다. **경제 규칙과 기존 기대값은 바꾸지 않는다.**

**알림 — MANIFEST:** `5579c1b`에서 MANIFEST 해시가 맞지 않은 것은 너의 잘못이 아니다. Claude가 스냅숏 전에 `MANIFEST.json`을 되돌렸다. 이번에도 끝에 `build_package.py --manifest-only`를 실행해 갱신해 두면 된다.

## 고칠 것

### minor

1. **저장 모양 검사의 테스트가 검사를 지키지 못한다** (`m2a-growth.test.ts` 454·466행 부근).
   - 문제: `checkSaveShape`를 `phase`만 보게 줄여도 테스트가 통과한다. 기존 사례는 다른 이유로 실패하고 있다(불변 조건의 TypeError, 근무 시작일 비교).
   - 고칠 것:
     - 다음 손상을 **각각** 시험한다:
       - `offers: [null]`
       - `log: null`
       - `recruitment.scoutedVenueIds: null`
       - 직원 `availableFromDay`가 문자열
       - 장부 항목 `lines`가 객체
     - 모두 SaveError이고, 메시지에 손상된 경로(예: `state.offers[0]`)가 들어 있어야 한다. 그래야 다른 이유로 실패하는 경우와 구별된다.
     - 메타 정보 대조(`save.ts` 112~114행)를 시험한다.
     - 설정 없이 판본 4를 불러오는 경로(화면이 쓰는 경로)를 시험한다.
   - 확인용 변형:
     - `checkSaveShape`를 `phase`만 보게 줄이면 실패해야 한다.
     - 배열 원소 검사를 빼면 실패해야 한다.
2. **`save-shape.ts`가 엔진의 열거값(통화·계정·업무 종류·상태 등)을 손으로 복사했다.**
   - 문제: 나중에 엔진에 값이 추가되면, 그 값을 쓴 저장을 모두 불러올 수 없게 된다. 타입 검사도 이를 잡지 못한다.
   - 고칠 것:
     - 가능하면 엔진의 실행 시점 상수에서 목록을 만든다. 예: `ACCOUNT_KIND`의 키, `MINOR_PER_MAJOR`의 키.
     - 실행 시점 상수가 없는 유니언은 전수 목록을 `satisfies Record<유니언, true>` 같은 방식으로 정의한다. 값이 추가되면 `tsc`가 실패하게 하기 위해서다.
     - 각 목록이 타입과 맞는지 확인하는 테스트를 하나 둔다.
3. **불러오기가 ID 중복과 참조를 확인하지 않는다.**
   - 문제: 직원 항목이 중복된 판본 4 저장이 불러와진다.
   - 고칠 것:
     - 직원·업무·계약·장부 항목 ID의 중복은 SaveError로 거절한다.
     - 다음 참조가 가리키는 직원이 없어도 SaveError다: 업무 담당자, 계약 담당자, 영입 후보.
     - 이미 불변 조건이 확인하는 것은 다시 만들지 말고, 빠진 것만 더한다.
4. **`trainingPreview`가 AWAITING_INPUT이 아닌 단계(PENDING_OPEN·ENDED)에서 `allowed: true`를 돌려준다.** 하지만 실제 `commitDay`는 예외를 낸다.
   - 고칠 것:
     - 그 단계에서는 `allowed: false`와 읽을 수 있는 이유를 돌려준다. 예: ‘하루를 연 뒤에 훈련을 시작할 수 있습니다’, ‘캠페인이 끝났습니다’.
     - 두 단계 모두 테스트한다.
5. **미리 보기의 사용 가능액이 엔진 거절 문구와 다른 계산일 수 있다** (`previews.ts` 12행).
