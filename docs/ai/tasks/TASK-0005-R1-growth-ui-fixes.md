## A. 표시 수정

1. **[minor] M1은 그대로** (`card.ts` `showGrowth`, `crew-status.ts` `crewNoteKo`).
   - M1(성장이 꺼진 시나리오)의 카드는 이전과 똑같아야 한다.
     - ‘레벨 1 · 강화 +0’ 줄을 보인다.
     - 접근 이름에 ‘레벨 1’을 넣는다.
   - 성장이 꺼진 시나리오에서 숨기는 것은 새로 생긴 것뿐이다: 주·부 능력 줄, 상세, 훈련, 경험치.
   - M1 직원 각주는 이전 문장을 그대로 쓴다: ‘처리량은 고정값(LEGACY_FIXED, 하루 2pt)만 씁니다. 능력·속성·레벨·시너지는 이후 M2a 단계(성장)와 M2b에서 켭니다.’
     - ‘하루 2pt’는 아래 2번처럼 실제 값으로 만든다.
   - 시험: M1 카드 HTML과 각주를 고정한다(이전 화면 문자열과 같음).
2. **[minor, Claude 결정] ‘하루 Npt’의 N은 실제 값이다.**
   - 원래 지시서의 ‘처리량(하루 Npt)’에서 N은 자리표시자였다. 지금 화면에는 글자 ‘N’이 그대로 나온다.
   - 직원 정의의 `workUnitsPerDay`로 채운다(지금은 모두 2 → ‘하루 2pt’). 직원마다 다르면 ‘하루 2~3pt’처럼 범위로 쓴다.
   - 시험: 성장 시나리오와 M1 각주에 ‘N’이 없고 ‘하루 2pt’가 있다. 서로 다른 값을 넣은 설정에서는 범위 문구가 나온다.
3. **[minor, Claude 결정] 여러 레벨을 한 번에 넘을 때의 알림.**
   - 지금은 ‘레벨 2 달성 (교섭 +2, 협업 +1)’ 다음에 ‘레벨 3 달성 (교섭 +4, 협업 +2)’가 나온다. 두 번째 줄이 하루 시작 대비 누적값이라 두 줄을 더하면 +6/+3으로 읽힌다.
   - 각 줄은 **그 단계의 증가분**을 보인다: ‘레벨 2 달성 (교섭 +2, 협업 +1)’, ‘레벨 3 달성 (교섭 +2, 협업 +1)’. 두 줄의 합이 실제 변화(+4/+2)와 같다.
   - 증가분은 각 단계의 `levelProgress` 값끼리의 차이로 구한다. 화면이 성장 규칙을 다시 계산하지 않는다.
   - 시험: CHAR-ACC-02 경로에서 두 줄의 증가분 합이 54−50, 42−40과 같다.
4. **[minor] 대기 중이거나 진행 중인 훈련의 블록** (`growth.ts`):
   - 훈련을 대기 명령에 넣으면 상세는 `view`(상태 + 대기 명령)로 그려진다. 그래서 ‘지금 → 훈련 뒤’ 금액과 ‘지금 N일까지 → 훈련하면 M일까지’가 **두 번째 훈련**을 가정한 값이 된다. 방금 넣은 훈련의 비용이 한 번 더 빠지는 것처럼 보인다.
   - 그 직원이 이미 훈련 중(대기 포함)이면 ‘→ 훈련 뒤’, ‘→ 훈련하면’ 부분을 보이지 않는다. 대신 상태 줄을 보인다: ‘◆ 교육 중 0/1일 — 훈련비 50,000원 반영됨. 완료하면 +60 경험치’.
   - 값은 엔진에서 받는다(`runningTaskOf`, `trainingPreview`의 비용·경험치).
   - 시험: 훈련을 대기에 넣은 뒤 상세에 ‘훈련 뒤’와 ‘훈련하면’이 없고 상태 줄이 있다.
5. **[nit] 필터 이름:**
   - ‘업무 중’ 필터에 교육 중인 직원도 들어간다. 이름을 ‘업무·교육 중’으로 바꾼다.
   - 엔진의 바쁨 판정은 그대로 둔다.
6. **[nit] M1 원화 보고:**
   - 영입·성장이 없는 시나리오에서는 항상 0인 ‘영입 계약금’·‘훈련비’ 행과 그 각주를 빼라.
   - 남은 행으로 현금 등식이 성립해야 한다.
   - 시험: M1 보고 행. 성장 시나리오의 7행은 그대로.
7. **[minor·기존 결함] 선택 카드 가로 넘침** (`style.css`):
   - 선택 카드에는 `perspective(700px) rotateY(-6deg)` 기울기가 걸린다. 화면 폭 1024~1100에서는 한 열 배치라 카드가 950~1040px로 넓어지고, 그 투영이 틀을 5~13px 넘어 가로 스크롤이 생긴다(Claude 실측. 개발 브랜치에도 있음).

   - 기울기 효과와 ‘움직임 줄이기’ 설정은 그대로 둔다.
   - 시험: CSS 문자열 시험. 브라우저 확인은 Claude가 한다.
