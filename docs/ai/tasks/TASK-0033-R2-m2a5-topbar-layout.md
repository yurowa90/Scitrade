## 구현 지시

### 1. 위쪽 막대(측정 1)

- 지금 상태: 규칙 2에서 폭이 1220px 이하면 막대가 두 줄로 접힌다.
  - 높이: 터치 79 → 134.6px, 마우스 72.3 → 127.9px, 390px 폭 223.8px.
  - 폭 1180 이하에서는 ‘하루 진행’이 둘째 줄 왼쪽으로 내려간다.
  - 원인: ‘원화 급여 가능일 (임차료 포함 · 오늘 할 일 반영)’ 칸이 230px이다(다른 칸은 103~129px).
- 고침:
  - 막대의 칸 이름은 ‘원화 급여 가능일’만 둔다. 괄호 설명(임차료 포함 · 대기 중인 명령 반영)은 `title` 속성과 접근 가능한 설명(`aria-describedby`가 가리키는 숨김 글 또는 막대 아래 작은 글)으로 옮긴다.
  - 지급 불이행 단계 칸도 같은 규칙으로 줄인다.
  - R1 지시 4의 ‘대기 중인 명령 반영’ 표시는 이 설명으로 옮긴다. 막대 본문에서는 뺀다.
- 조건:
  - 규칙 2 막대는 폭 1024px 이상에서 한 줄이다.
  - ‘하루 진행’ 단추의 위치(막대 안 순서와 줄)는 같은 폭에서 규칙 1과 같다.
  - 390px 폭 막대 높이는 규칙 1의 같은 폭 높이에 칸 하나 몫(줄 하나)까지만 더해질 수 있다. 측정값을 결과 보고에 적는다.

### 2. 시세표 가로 스크롤 칸(측정 3)

- 지금 상태: iPad mini 가로(636px 칸에 672px 표)와 390px 폭(335/672)에서 시세표가 가로로 스크롤된다. Chromium은 스크롤 칸을 Tab 정지점으로 넣는데, 그 칸에 이름이 없다.
- 고침: 스크롤 칸에 `role="region"`과 `aria-label="시세표 (가로로 넘겨 보기)"`를 준다. 키보드 초점이 보이게(`:focus-visible` 테두리) 한다.
- 표 폭을 줄여 스크롤 자체를 없애는 것은 이번 범위가 아니다. 줄일 수 있으면 결과 보고 ‘범위 밖 발견’에 방법만 적는다.

### 3. 선택지가 하나인 수량 칸(측정 4)

- 선택지가 하나면 `<select>` 대신 같은 자리에 글(예: ‘수량 100벌’)을 보인다. Tab 정지점에서 빠진다.
- 선택지가 둘 이상이면 지금처럼 `<select>`다.
- R1에서 환전 금액을 `<select>`로 바꿨다면, 같은 규칙(선택지 하나면 글)을 적용한다.
