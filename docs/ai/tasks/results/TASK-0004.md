## 설계 판단 (지시서에 없던 결정과 이유)

1. `xpAwards: Record<string, true>`를 유지하고 같은 키의 `xpAwardAmounts`를 추가했다. 불변 조건에서 시작 경험치와 실제 지급액 합계를 대조하며, 키·금액 기록 중 한쪽이 누락돼도 탐지한다. 레벨·최종 능력은 저장하지 않는다.
2. 계산·보상 함수를 `growth.ts`로 분리했다. 실제 업무의 `TASK-DONE-<ID>` 보상은 완료 여부·담당 직원·보상 종류·설정 지급량을 확인한다. 훈련에 일반 업무 보상을 더하려는 요청도 거절한다. 한 번에 여러 레벨을 넘으면 각 도달 레벨을 로그에 남긴다.
3. 훈련은 기존 `Task` 진행 필드를 재사용하되 `TRAINING`에서만 일수로 해석한다. 일 마감마다 1씩 증가시키며 `workUnitsPerDay`나 최종 능력을 곱하지 않는다. 기존 일정 설명도 `pt` 대신 `일`을 쓴다.
4. 훈련 거절은 `processedCommands`도 바꾸지 않는다. 기존 명령의 거절 기록 정책은 유지하고, 새 `START_TRAINING`에 지시서의 상태 전체 보존 조건을 적용했다. 성공한 훈련 명령은 기존 명령 ID 중복 방지를 따른다.
5. 저장 이관은 기본적으로 저장 시나리오를 로드해 직원의 `startXp`를 얻는다. 설정 사본 검증을 위해 `deserializeSave`에 선택적 `config`도 받는다. 과거 완료 업무는 소급 보상하지 않는다.
6. 훈련비는 급여·영입비·계약 기여이익과 별도 집계한다. 실제 훈련 지출은 총손익 `profit`에 비용으로 반영해 자산·자본·부채 등식을 유지한다. 훈련 없는 기존 경로의 모든 경제 요약값은 그대로다.
7. 현재 핵심 인수 명세에는 사례별 연결용 `status` 값이 없고 `engine_test_ref`가 있다. 이 연결 필드를 재사용하고, 캐릭터 명세의 연결 상태는 `EXECUTABLE_ENGINE_TEST_LINKED`로 명시했다. 상위 상태는 일부 연결로 표시하고 나머지 5개 명세는 미실행 상태를 유지했다.

현재 코드와 지시서 설명의 차이:

- 카드 레벨은 캐릭터 JSON을 읽는 방식이 아니라 문자열 `레벨 1`로 고정되어 있었다. 카드 본문과 접근성 설명을 모두 상태의 누적 경험치로 계산하도록 바꿨다.
- 검사기에는 경험치 문턱 공식 검사가 이미 있었다. 이를 유지하고 1~10 전체 문턱의 존재·순서, 성장 중심의 능력 참조, 훈련 양의 정수 조건을 보강했다.
- 기존 저장 테스트가 명시적으로 판본 3을 단언했다. 이번 지시의 판본 4 변경에 필요한 단언만 갱신했다. 판본 2 fixture는 성장 이전 상태로 생성하여 완료 업무의 소급 보상을 기대하지 않게 했다.

## 완료 조건 대조 (지시서의 조건마다 충족/미충족과 근거)

1. **충족 — 경험치 한 번 지급.** 직원·완료 사건·보상 종류 키로 중복을 막는다. 두 직원의 개별 업무 및 같은 사건 보상, 재전송, 저장 후 재처리, 미완료·중단 업무 거절, 조사·영입 의뢰 완료 보상을 검사했다.
2. **충족 — 누적 경험치에서 동일하게 재계산.** CHAR-ACC-02 설정 사본에서 90+230=320, 레벨 3, 능력 54/42를 확인했다. 재계산·저장 전후 동일, 모든 문턱의 직전·정확한 값, 최대 레벨 10과 능력 100 상한을 검사했다.
3. **충족 — 훈련 예약·비용·급여 분리.** CHAR-ACC-08에서 훈련비 20,000원·급여 10,000원·총지출 30,000원·끝 현금 470,000원·경험치 60을 확인했다. 훈련 중 준비 배정 거절·다음 날 배정, 이틀 훈련 저장 재개, 처리량 0/100에서도 하루 1일 진행, 자금 부족·미지급 의무·후보·근무 시작 전·다른 도시·업무 중 거절 시 상태 전체 보존을 검사했다.
4. **충족 — 기존 검산 유지.** 기존 116개 테스트 통과. 허용된 저장 판본 단언과 과거 저장 fixture 준비 외에는 기존 기대값을 수정하지 않았다. M1 정상 현금 10,150 USD, M2 17일 현금 3,500 USD·급여 2,720,000원 유지. M2 귀솔 경험치 20·물보리 10이며, 성장 비활성 및 시작 레벨 10 설정과 비교해 장부·업무·운송이 동일하다.
5. **충족 — 검증과 보고.** 필수 검증 다섯 개 통과, 이 결과 보고서 작성. 경험치 불일치·지급액 누락·중단 업무 보상·훈련비 중복이 불변 조건에서 탐지된다. 판본 1·2·3에서 새 필드를 실제로 삭제한 저장을 4로 이관하는 경로도 통과했다.
