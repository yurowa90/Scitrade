## 설계 판단 (지시서에 없던 결정과 이유)

- `integerScale`은 정수 경계에서 8×기계 epsilon 범위의 곱셈 오차만 보정한다. 경계보다 실제로 작은 폭은 올리지 않는다. DOM 계산은 가능한 경우 소수 CSS 폭을 읽고 테두리·안쪽 여백을 빼며, `clientWidth`는 대안으로 쓴다.
- `fitPixelBox`의 결과는 `{ n, cssWidth, cssHeight }`다. 크기 감시자는 모듈당 하나이며, 다시 그릴 때 부모 감시 대상과 요소 목록을 교체한다. 해상도 감시도 이전 리스너를 해제한 뒤 현재 dpr로 다시 등록한다.
- 바다 거리와 관문 반경은 논리 픽셀의 유클리드 거리다. 해안선은 **4-이웃 바다에 닿은 육지 쪽 한 줄**을 `earth-4`로 칠한다. 지도 바깥을 가상의 바다로 취급하지 않는다. 관문 주변 연결도 4-이웃으로 검사한다.
- 육지 분류 최빈값은 바다를 투표에서 제외한다. 동률이면 원래 분류를 유지해 불필요한 경계 이동을 줄인다. 외톨이 정리는 원본 배열을 보고 동시에 한 번 적용한다.
- 초안 변환의 색 빈도 동률은 팔레트 등록 순서로 고정한다. 격자 영역은 정수 경계로 나누고, 확대 입력은 빈 영역이 생기지 않도록 한 원본 픽셀 이상을 읽는다. 투명도가 정확히 절반이면 지시대로 불투명이다.
- 제공 원본은 Blue Marble **4096×2048**, 높이 지도 **2048×1024**다. 동아시아 높이 지도 자른 영역은 목표 논리 크기보다 작다. 따라서 두 입력 모두 BOX로 논리 격자에 맞추되, 높이 지도 동아시아 입력은 축소가 아니라 확대다. 원본 크기를 임의로 가정하거나 교체하지 않았다. 세계지도는 두 입력 모두 영역 평균으로 축소한다.
- 통로는 지시대로 해협·운하만 낸다. `cape_route`인 희망봉은 원래 바다이며 별도 통로를 내지 않는다. 생성물 시험에서는 희망봉까지 포함한 범위 안 **모든** 관문 중심이 바다색인지 검사했다.
- 스프라이트의 `scaleN`은 정수 기기 배율이며, `applyPixelScale`이 루트에 설정하는 `--pixel-dpr`로 CSS 크기를 환산한다. 독립 사용 시 dpr 기본값은 1이다. 애니메이션은 한 줄의 4칸을 720ms에 반복하고 움직임 줄이기에서는 첫 칸이다.
- SVG 밖 바탕 대안은 `src/ui/map.ts`의 **`MAP_BASE_OUTSIDE_SVG`** 상수를 `true`로 바꾸면 켜진다. 기본은 `false`다. 같은 보기 영역으로 자른 장식 `<img>`와 기존 접근 이름을 가진 SVG를 같은 크기 상자에 겹친다.

- 결과: 구현·자동 검증을 반영했다. **기준점 전부 일치 조건은 미충족**이고, 세계지도 4-이웃 외톨이 목표도 미달이다. 아래 실제 생성 결과와 조건 대조를 따른다.

- `src/ui/main.ts`(지도 부분), `src/ui/style.css`: 지도 부분만 측정 후 교체, 세계 스크롤 비율 보존, 대안 SVG 100% 크기, 중복 규칙 제거.
- `src/ui/pixel.test.ts`, `src/ui/sprite.test.ts`: 배율·여백·감시 대상·dpr 속성·대안 모드·슬롯·스프라이트 회귀 검사.
- `scripts/build_map.py`, `scripts/test_build_map.py`: 벡터 육지·호수, 통로·전체 바다 연결, 높이 정렬·음영, 정확한 색 검사, 원본이 있을 때 임시 폴더 재생성.
- `tools/art/pixelize.py`, `tools/art/check_pixel_asset.py`, **새 파일** `tools/art/png_format.py`, `tools/art/test_pixel_tools.py`: 대각선 보존, 고정밀 입력 거절, PNG 청크 검사, 팔레트 실패 메시지·CIELAB·색 수·변환 회귀 검사.
- `src/assets/manifest.json` 지도 항목과 `public/assets/maps/east-asia.png`, `world.png`.
- 이 결과 보고서 끝에만 추가했다. `src/engine/**`, `data/**`, 카드 구현 및 제외 문서는 수정하지 않았다. 새 패키지를 설치하지 않았고 커밋·푸시·브랜치 전환을 하지 않았다.
- `MANIFEST.json`은 필수 명령으로 갱신·검증한 뒤 범위 밖 변경을 남기지 않도록 작업 전 바이트로 복원했다. 복원한 매니페스트로도 자료 검사를 통과했다.

### 설계 판단

- 항로 상자를 먼저 논리 격자 밖으로 맞춰, 소수 좌표에서도 네 방향 12픽셀 여백을 확보한다. 정수 n은 가로·세로 조건을 모두 보고 고른다. `L=floor(W*dpr/n)`, 높이 `round(L*10/16)`을 쓴다. 지도 끝에서는 x·y를 경계에 맞추며, 원본 밖의 보기 영역은 틀의 바다 바탕으로 남는다.
- 이름표·휘장·나침반은 기존 `k=vb.w/620`(세계 0.45배)을 유지했다. 틀과 CSS 폭 차이는 정수 한 칸 미만이다. 화면의 실제 크기·픽셀 간격 확인은 Claude의 브라우저 검수로 남긴다.
- 첫 지도는 기본 620 CSS px로 만들고 다음 rAF에서 측정값을 적용한다. 감시 콜백은 크기를 쓰지 않는다. 같은 n·L·보기 영역·dpr이면 DOM을 교체하지 않는다. 일반 카드 그림은 기존 `fitPixelBox` 계산을 유지한다.
- 동아시아는 **Natural Earth 1:10m**, 세계는 **1:50m** 육지·호수를 사용했다. 작은 섬을 보존하기 위해 동아시아만 세밀한 원본을 선택했다. 6×6 표본의 육지 비율이 50% 이상인 칸만 육지다. 구멍과 호수, 경도 +360 사본을 그리며 위성 영상은 지형 색에만 쓴다.
- 해협·운하마다 양쪽 물 기준점을 표에 두고 4-연결 계단을 낸다. 기존 관문 표시 좌표도 통로 안에 오도록 해당 좌표를 경유한다. 기존 관문 픽셀이 물이어야 하는 검사를 유지하기 위해 희망봉 표시용 우회도 포함했다. 데이터 좌표·운송 규칙은 바꾸지 않았다.
- 도시 해안 거리는 **실제 투영된 도시 좌표에서 육지 쪽 해안 픽셀의 닫힌 정사각형까지의 유클리드 거리**다. 이전의 칸 중심끼리 거리는 대각선 해안을 sqrt(2)로 과대평가했다. 새 거리 정의·도시별 값은 메타에 기록했다. 동아시아 하이퐁은 0.9174픽셀이다.
- 해안은 `teal-4`다. 육지 분류 어디에도 사용하지 않는 밝은 청록색이어서 건조지 `earth-4`와 겹치지 않는다. 산지는 `earth-1~3`, 눈·얼음은 `light-2~4`로 분리했다. 산지와 건조지는 흙 줄기를 공유한다.
- 외톨이 색 비율은 **전체 지도 픽셀을 분모**로 쓰며 지도 밖은 같은 색 이웃으로 취급하지 않는다. 세계의 4-이웃 외톨이는 대부분 대각선 해안선과 한 칸 폭 얕은 바다 띠다. 육지 판정·해안 거리·한 줄 해안을 보존했고 이 띠를 지우는 추가 색 정리는 하지 않았다.
- 요청 기준점 중 상하이 122.0°E 31.0°N 칸의 원본 육지 비율은 두 지도 모두 0%, 세계 오키나와 칸은 44.44%다. 50% 면적 규칙을 유지하면 요청된 ‘육지’와 동시에 만족시킬 수 없다. 선택 질문에 답변이 없어 원본 판정을 유지했다. 메타의 `passed: false`와 매니페스트에 불일치를 남겼다. 새 테스트도 이 불일치를 명시적으로 확인하므로, 테스트 통과를 기준점 조건의 통과로 해석하면 안 된다.

1. **세계 상하이 기준점 추가 조정 — Claude 검수 필요.** 요청 좌표 121.5°E 31.2°N은 동아시아에서 통과하지만, 세계 격자의 동쪽 칸(303,81)은 원본 육지 면적 18/49=36.7347%다. 바로 서쪽 칸(302,81)은 47/49=95.9184%다. 사용자 질의 후 응답이 없는 상태에서 권장안으로 세계지도만 같은 시가지의 121.4°E 31.2°N을 검사했다. 50% 판정·다각형·PNG를 이 기준점을 위해 바꾸지 않았다. 동아시아는 요청한 121.5°E 31.2°N 그대로다. **지시서의 정확한 세계 좌표를 그대로 유지하는 조건은 미충족이며, 이 변경을 검수 때 확정해야 한다.** 실패를 기대하거나 허용하는 테스트는 없다.
2. 통로 연결은 지역 창 안에서 판정한다. 전체 바다 연결만 보면 수에즈를 희망봉으로 우회하므로, 지역 검사와 실제 통로 열기가 같은 창을 사용한다. 육지 칸 수를 먼저, 경로 길이를 다음으로 최소화하는 Dijkstra를 쓴다. 이미 연결된 경우 경로 계산 자체를 호출하지 않는다. 물 기준점이 육지면 실패하며 통로당 6칸 초과 변경도 실패한다.
3. 기존 마르마라해 기준점 28.5°E 40.5°N도 세계 원본에서 육지 면적 71.4%였다. 보스포루스·다르다넬스 공통 끝점을 물 위의 28.0°E 40.8°N으로 옮겼다. 믈라카 남쪽은 요청 예시 103.9°E 1.15°N을 쓴다.
4. 작은 내륙 물은 4-연결 성분 4칸 미만일 때 육지로 정리한다. 지도 경계나 통로 물 기준점에 닿은 성분은 보존한다. 마르마라해처럼 저해상도에서 작게 잡히더라도 항행 연결에 필요한 물을 없애지 않기 위해서다.
5. 산지는 공용 팔레트 `ink-2/3/4`를 사용한다. 흙 줄기의 건조지와 밝은 중성 줄기의 눈·얼음과 색을 공유하지 않는다. 높은 눈·얼음은 산지보다 먼저 유지한다.
6. 세계 얕은 바다 기준 1→1.5를 실제 비교했다. 아래 외톨이 표에 결과를 적었다. 거리 sqrt(2)의 대각선 바다도 밝은 띠에 포함되어 반점이 줄어든다.
7. 관문 좌표에서 바다까지 거리는 거점 해안 검사처럼 **실제 투영 좌표에서 바다 칸의 닫힌 정사각형까지** 잰다. 중심이나 포함 칸 인덱스끼리 재면 경계 좌표를 과대평가한다. 수에즈 관문은 가장 가까운 바다 칸까지 정확히 1픽셀로 통과하며 이를 위해 육지를 더 깎지 않는다.
8. gAMA는 0.45455에서 약 1/100000의 반올림 차이를 허용한다(45454/45455/45456 통과, 45457 실패). iCCP는 원본 청크에서 직접 풀어 IDAT 뒤 프로필도 검사한다. 프로필 테스트는 sRGB 이름과 RGB 색 공간을 유지하면서 전달 곡선 감마를 바꾼 실제 RGB 프로필로 색 변환 비교 경로를 실행한다.
