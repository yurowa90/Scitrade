- 화면 읽기 알림: `<상세 제목>: 지도 아래에 자세한 내용`.
- 거점 역할·선정 근거·메모·개방 단계, 해협 연결·사건 글은 기존 SVG 제목과 같은 자료를 쓴다. 개방 단계는 ‘이번 시나리오 거점’ / ‘1장 <단계> 단계에서 열림’ / ‘세계 확장(2장)에서 열림 — 지금은 지도 미리 보기’. 해협 마지막 줄은 ‘세계 확장(2장)에서 항로 선택·사건과 연결 예정’.

## 범위 밖 발견

- 전 세계 목록은 27곳에 운항 중인 배가 더해져 길다. 기본 `<select>`의 `<optgroup label>`로 묶었다. 실제 화면 읽기 프로그램에서 묶음 이름을 읽는지는 이 작업에서 측정하지 않았으며 Claude 검수 대상이다.
- 목록은 지도 틀 밖에 있다. 새 코드가 방향키를 가로채지 않아 목록 초점에서는 브라우저 기본 목록 조작, 지도 틀 초점에서는 기존 가로 스크롤을 쓴다. 실제 Chromium·기기 키보드 검증은 Claude가 한다.
- 브라우저·실제 키·누르기 측정은 지시대로 실행하지 않았다. 15개 시나리오와 7개 프로필의 실제 위치·높이·쪽 오류·Tab 순서 확인은 Claude에게 남긴다.
