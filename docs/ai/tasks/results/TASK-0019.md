- 모든 문자열 잎을 지정 정규식으로 나눈 조각을 문장 단위로 센다. ID·URL·상태 문자열도 포함한다. 출처 문서는 문장 검사에서 제외한다. 현재 6,933문장·53표지로 원형 수치와 같다.
