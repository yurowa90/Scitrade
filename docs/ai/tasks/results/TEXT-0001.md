### 가장 시급한 5건

1. **[T-001] 직접 무역의 수출자 도착지 수입 관세 부담·운임 선지급을 실제 무역의 일반 원칙처럼 서술 (`src/ui/main.ts:596`, `src/ui/main.ts:597`, `src/ui/main.ts:618`, `src/ui/main.ts:863`)**
   - 직접 무역 카드에서는 수출자인 회사가 도착지 수입 관세와 선지급 운임을 모두 내고, 운송 주선 카드(`main.ts:618`)에서만 `관세: 수입자 부담 (회사 0)`으로 대조하고 있음. 실제 무역에서는 인코텀즈(Incoterms)의 DDP 조건 등 예외적인 경우가 아니면 직접 무역에서도 도착지 수입 관세는 수입자(고객)가 부담하며, 운임도 조건(FOB·CIF 등)과 선하증권 조건(Prepaid/Collect)에 따라 부담 주체와 지급 시점이 다름. 게임의 단순화 규칙(수출자가 운임·관세를 모두 부담하는 가상 조건)임을 명시하지 않아 학생이 “직접 수출할 때는 원래 수출자가 수입국 관세를 다 내고, 주선할 때만 수입자가 낸다”고 오개념을 가질 위험이 큼.
2. **[T-005] 환전 환율의 ‘받을 때’·‘살 때’ 표기 모호성 (`src/ui/market.ts:92`)**
   - `게임용 고정 환율 ${fx.buyKrwPerUsd.toLocaleString('ko-KR')}원(받을 때) · ${fx.sellKrwPerUsd.toLocaleString('ko-KR')}원(살 때)`에서 무엇을 받고 무엇을 사는지가 생략되어 있음. 뒤쪽 `살 때`는 ‘달러(USD)를 살 때’인데 앞쪽 `받을 때`는 ‘달러를 팔아 원화를 받을 때’를 줄인 말이라 목적어 기준이 서로 다름. 고등학생이 외환의 매입률·매도율 개념을 처음 접할 때 큰 혼란을 줄 수 있음.
3. **[T-012] 상황실 출처 등록부 표에 내부 영문 열거값(`bundle_raw`, `derived_only`) 그대로 노출 (`src/ui/situation.ts:126`)**
   - `${esc(l.license_tier)}`가 한국어 변환 없이 그대로 출력되어 학생이 보는 표 칸에 `bundle_raw`, `derived_only`라는 개발용 영문 식별자가 노출됨.
4. **[T-015] ‘묶음’이라는 한 단어가 ‘견적 공개 회차(batch)’와 ‘환전 단위(100 USD lot)’와 ‘소포장 단위(pack)’ 세 가지 뜻으로 동시에 쓰임 (`src/ui/market.ts:21`, `src/ui/market.ts:81`, `src/ui/warehouse.ts:63`, `src/ui/recruitment.ts:100`)**
   - 같은 화면 안에서 `이번 묶음 견적 있음`·`최근 4묶음`(`batch` = 주간 견적 회차)과 `1묶음`(`lot` = 100 USD 환전 단위)이 함께 나와 학생이 두 개념을 구분하기 어려움.
5. **[T-056] 1024px 상단 상태 막대(`.operations-statusbar`)의 ‘지급 상태’ 칸에 60자 안팎의 문장이 들어가 머리 줄 배치 붕괴 위험 (`src/ui/market.ts:105`, `src/ui/market.ts:112`)**
   - 상단 상태 막대에 8개 항목이 가로로 나열되는데, 지급 경고·위험 시 `<b>` 안에 `${stage} · 실패까지 ${remaining}일 · ${config.campaignDays}일 캠페인이 끝날 때까지 갚지 못하면 미지급을 남기고 끝납니다`와 `<small>하루 진행 뒤 예상: ...</small>`까지 함께 들어가 1024px 화면에서 줄바꿈이 과도하게 일어나거나 상단 고정 막대 높이(`--topbar-h`)가 크게 늘어날 위험이 있음(추정).

  - 작업 범위: CLI 로그에 `workspaceDirs=[<사용자 Mac의 저장소 최상위>]`가 찍혔다. 실행한 폴더(저장소 최상위)를 작업 범위로 잡는다.
  - `--effort`와 모델 ID: 실제 실행에는 `--effort`를 주지 않았고, 로그에 `label="Gemini 4 Argon (Medium)"`가 찍혔다. 따로 시험해 보니 `--model gemini-4-argon-medium --effort high`는 어느 한쪽이 이기지 않고 `--model gemini-4-argon-medium conflicts with --effort=high` 오류로 종료 코드 1이 났다. 추론 수준은 모델 ID 접미사로만 정한다.
- 세션 T 표본 대조(검수가 아님): 65건 모두 표의 `파일:줄`에서 원문 앞 30자를 찾아봤다. 64건은 해당 줄에 그대로 있었다. T-055는 원문 앞에 윗줄(135행)의 `return \``이 붙어 있어 “원문 그대로”와 조금 어긋난다. 지적 내용의 타당성(사실·용어 판단)은 검토하지 않았으므로 허브 검수가 필요하다.
