# 고전게임 인사이트 기획 반영 결과

- 요청: 에어 매니지먼트·캐피탈리즘·도서관 성장 게임 등의 인사이트를 Scitrade에 반영.
- 범위: 기획 문서와 기존 구현 단계의 검증 기준 보강. 최초 로컬 작성 단계에서는 코드 수정·커밋·푸시 금지 조건을 유지했다. 이후 사용자가 GitHub 게시를 요청하여 이번 문서·manifest의 커밋·푸시와 인계 PR을 허용했다. 게임 코드·배포는 변경하지 않는다.
- 기준: PR #1 head `8590193ce895654def50b34e7226499e880e1058`. 기존 로컬 저장소가 확인되지 않아 별도 로컬 checkout에서 작업했다. 다른 작업의 checkout은 변경하지 않았다.
- 입력: 기존 플레이 기록 시트, 캐피탈리즘 2 공식 매뉴얼, DESIGN·STATUS·DECISIONS·IMPLEMENTATION_PLAN·RESEARCH_APPLICATION.
- 출력: `docs/CLASSIC_GAME_INSIGHTS.md`, 연구 적용표·구현 계획·문서 지도 진입 링크, 자료 manifest 갱신.
- 사용자 행동의 목표: 관심 발견→제약 파악→수주·배치·성장·탐방 선택→경영/동료/문화 결과→재계획·다음 만남.

1. 에어 매니지먼트 2: 부문 수익과 회사 손익 구분, 선지출과 미래 가동·결과의 시점 구분.

4. PM2·심시티·문명 기록: 육성의 시간 기회비용과 확장·연결의 판단. 검증되지 않은 인과 계수는 제외.
5. 동료의 애착과 문화 발견 자체의 보상을 보존. 모든 경험을 수익·효율 보너스로 환원하지 않음.
