## 6. 반영 제안
1. 성취기준은 기존 연결 ID·내용 요소와 분리한 `achievement_standards` 칸에 둔다. 아래 47개 JSON 조각은 **제안 목록**이다. ETH01~06만 직접 근거가 확인되어 값이 있다. 나머지 41개 빈 배열은 접근 실패로 보류한다는 뜻이며 자료에 빈 배열을 일괄 반영하거나 “해당 성취기준 없음”으로 확정하지 않는다. 먼저 Claude가 C6 문장·판본을 교차 확인한다. 최상위 성취기준 목록을 코드+판본별로 한 번 관리하면 여러 연결에서 같은 문장이 달라지는 문제를 줄일 수 있다. 현 6건은 중복 코드가 없어 연결별 별도 칸도 가능하다. 스키마·검사기 선택은 W2-0a/W2-0b에서 결정한다.

2. 머리 칸은 `current_edition_comparison_status: "partial"`을 제안한다. 실제 비교 완료 0/47임을 함께 적어 `partial`을 일부 현행 일치 판정이 있다는 의미로 오해하지 않게 한다. 확정 현행판 번호를 담는 칸은 `current_edition: null`, 열람일 `edition_checked_on: "2026-10-09"`, 발견한 가장 최근 번호는 별도 `latest_notice_found: "2026-1"`로 기록하는 안이다. 2026-1을 공식 게시물에서 확인했지만 연혁 완전성과 개정문은 검증하지 못했다. `scope.achievement_standard_codes_included`는 **false 유지**다. 표 B의 41개 `없음`은 성취기준 부재 사유가 아니라 접근 실패이므로 전체 매핑 완료 조건을 만족하지 않는다.

3. 47개 `edition_comparison_status`는 표 A대로 모두 `current_edition_not_verified` 유지 제안이다. 2026-1 개정문과 현행 각론을 확인하지 않고 `current_edition_same`으로 바꾸지 않는다. “2026 개정은 총론만 바뀐 듯하다”는 검색 단서로 (나)를 적용하지 않는다.

4. P0 쌍 7개는 priority 승격 보류, 본문 원문 확보 뒤 확정한다. 잠정 처리안은 CA01→SOC10·NPC_MARKET→SOC10: 유지하고 P1 표시, NPC_GUIDE→SOC08·SOC12: P0 참조에서 연결 빼기, NPC_GUIDE→SCI05: 유지하고 P1 표시(현장 탐구 CA05 확장), VEN_CULTURE→SOC12: 장소의 P0 참조에서 연결 빼기, EV06→SCI09: P0 참조에서 연결 빼기다. “유지하고 P1 표시”를 채택하려면 P1 확장 참조를 P0 `curriculum_refs`와 구분하는 새 표현이 필요하다. 지금 스키마는 그 구분이 없으므로 실제 반영 전에는 P0 참조에서 빼거나 Claude가 예외를 명시해야 한다. 코드 미확인 SCI01로 대체하는 안은 채택하지 않았다.

   검사기 기본 규칙 문장 제안: “P0 항목의 `curriculum_refs`는 `priority`에 P0로 시작하는 표지가 있는 연결만 가리킨다.” `P0 보고`·`P0 설명`도 문자열 시작 조건으로 포함한다. 잠정 예외 후보는 CA01→SOC10, NPC_MARKET→SOC10, NPC_GUIDE→SCI05의 3쌍이며, 원문 대조와 P1 표시 표현이 확정될 때까지 승인된 예외는 **없음**으로 둔다. 나머지 4쌍은 근거가 있는 P1 활동의 참조로 이동할 수 있는지 별도로 검토한다. 이 보고서만으로 검사기를 강화하거나 기존 자료를 실패시키지 않는다.

5. `curriculum_links.json.activity_ids`는 없애고 `culture_activities.json.curriculum_refs`를 기준으로 역방향 목록을 산출하는 안을 권한다. 현재 SOC04·SOC07·SCI01→CA02 3건만 있어 전체 역방향 색인처럼 읽으면 빠짐이 많다. 저장본을 유지한다면 47개 연결 모두에 문화 활동만의 역참조를 생성·일치 검증해야 한다. 연락처·장소·사건 ID를 `activity_ids`에 넣을 수 없다(`tools/validate_data.py:514`). 서로 다른 자료 종류의 역참조가 필요하면 별도 칸을 설계한다. 이번에는 삭제·보충하지 않았다.

6. 확인한 ETH01~06의 요소·인쇄쪽은 일치하므로 문구·쪽 수정안은 없다. 사회·과학의 미확인은 불일치가 아니므로 수정하지 않는다. `pdf_page = printed_page + 6`과 그룹별 개수·ID·source_id를 유지한다. 향후 불일치가 확인되어 JSON 값을 바꾸면 DESIGN 17·18절 표도 함께 바꿔야 하는지 Claude가 정해야 한다. 다른 PDF의 쪽 차이가 다르면 자료의 인쇄쪽을 먼저 확정하고 +6 검사 규칙의 대상 PDF를 분리할지 결정한다. 이번 보고서에는 DESIGN 변경을 요구할 확정 불일치가 없다.

## 범위 밖 발견
- 신규 사회과 재게시 PDF 두 건도 표지에는 2022-33이지만 문서 제목에 시안이 있다. 기존 등록 C2와 다른 파일이므로 C2도 시안이라는 뜻은 아니다. 자료의 표지·쪽수만으로 확정본 여부를 판정하면 위험하다. 해당 파일들은 판정에서 제외했고 저장소에 넣지 않았다.
- `docs/DECISIONS.md:772`의 평택 전 CA02 메모는 지시서가 미리 확인한 그대로 낡아 있다. 수정 문장은 3절에 제안했으며 파일은 고치지 않았다.
- 교과 연결과 무관한 코드·경제 자료 문제는 이번 조사에서 확정하지 않았다. TASK-0020 결과 파일은 건드리지 않았다.

## 질문
추가 사용자 질문 없이 지시서 기본값으로 처리했다. Claude 검수 시 확인할 사항은 다음과 같다.

- SOC01~SOC18 및 SCI01~SCI23(총 41개)의 확정본 요소·성취기준을 확인하지 못했다. 이유는 교육부 ZIP 웹 도구 오류, C2 502, C3 및 추가 사회과 PDF의 시안 표시다. `없음`은 접근 실패이며 부재 판정이 아니다. 시간 부족으로 생략한 행은 없다.
- 47개 현행판 대조는 모두 확인 불가다. 2024-3의 공식 고시문은 읽었지만 사회과 별책7의 구체적 개정 내용·2026-1 개정문·법령 연혁 전체는 열리지 않았고 현행 별책 재게시 본문도 확보하지 못했다. 최신 발견 고시 2026-1을 현행 확정값으로 바로 반영하지 않는다. 2024-3 공식 고시문에 사회과 별책7이 포함되므로 “총론만 변경”으로 처리하면 안 된다.
- 표 B의 실제 코드 6건은 인쇄쪽을 확인했다. 인쇄쪽 미확인인 코드 행은 없다. ETH01~06의 다른 도메인 두 번째 본문 URL은 확보하지 못했다. C6의 생성일은 Claude 사전 확인값을 썼다. 문장·점·띄어쓰기와 공식 HWP 일치 여부를 Claude가 교차 확인해야 한다.
- 표 C 7쌍은 모두 애매할 때 기본값 `P1 확장 연결`을 적용했다. 7개 모두 성취기준 원문 대조가 남았고, 기준 코드가 없는 상태에서 P0 priority를 올리지 않았다. 6절의 제거/표시 처리안도 원문 확인 뒤 결정한다.
- ETH04·ETH05의 P0 보고 표시와 현재 참조 공백은 확정된 자료 사실이다. 제안한 EV04·EV06·CA05 소재는 윤리적 판단 문장을 추가해야 하는 후보이며 자동 연결 제안이 아니다.
- 기존 C1 기록의 `CONTENT_READ`·2026-10-04를 이번 게시물 열람으로 덮어쓰지 않는 안을 냈다. 기존 공식 HWP 확인 사실과 이번 접근 실패를 별도 이력으로 관리할지 결정이 필요하다.
- 6절 47개 JSON·표 F·표 D 자료 후보는 생략하지 않았다. 검사 스크립트와 직접 본 코드 꼴의 충돌은 없다. 형식 검사가 통과해도 원문 미확인 항목의 조사가 완료됐다는 뜻은 아니다.
