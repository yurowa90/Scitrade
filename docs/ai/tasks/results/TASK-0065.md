## 범위 밖 발견

- **HSK 2008.99-5010은 세션 C 확인(`ROUTE-4A-10B1-SOURCES`), 검사기 출처 조건 때문에 NOT_VERIFIED.** `sources.json` 원자료 항목·HS 판본이 없으므로 코드·판본 null 유지. VERIFIED 전환은 경로 7에서 세션 C와 진행한다.
- 학생에게 제공하려면 rules-3 시나리오 레코드·로더 분기·스키마가 필요하다. 검사기의 “operations는 M2a-rules-2 필요” 검사도 그때 이월 처리한다. 이번 실험은 상속된 rules-2 레코드다.
- claims bp·`partial_bp` 범위 좁히기는 경로 5 전 별도 작업이며 이번에 변경하지 않았다.
- 생성기 `generateBatch`는 주선 선택 전에 품목별 지수·판매지·시세·거래처 조정·물량을 뽑는다. 따라서 G가 달라지면 주선 난수 위치도 달라진다. 이는 코드 관찰이며 D 경제 측정은 하지 않았다. H18-6에 따라 시드 짝 차이를 판정에 쓰지 않고 변형별 분포 차이로 읽는 주의를 TASK-0066에 이어야 한다.
- 기준 문서 `HUB-DECISIONS-2026-10-16.md`의 이 BASE 파일에는 H18-5·H18-6만 있다. 나머지 H18 내용은 전달된 승인 지시서와 동결 설계 6절을 대조했다.
