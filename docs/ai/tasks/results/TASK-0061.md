### 세션 B 실측 요청

- 1024×768 터치: 공지 본문이 긴 상태에서도 브리핑·44px 레이어 토글이 스크롤 없이 보이는지, 항만 선택·범례·오른쪽 자료 스크롤.
- 1366×768: 지도 거점 이름·국가 휘장 겹침, 국가 카드가 지도 밖에 있는지, 표 전환 초점.
- 400% 확대: 한 열 배치·가로 넘침·토글·브리핑·닫기 접근.
- 화면 낭독: dialog 제목·Tab 순환·Escape 복귀, 토글당 한 번 낭독, 브리핑 status와 표 caption.
- reduced-motion: 스캔라인 없음·비네트만 있음·이동 클래스 없음·기존 지도 애니메이션 정지.
- 이 환경에서 Vite listen은 EPERM, Chromium은 setsockopt EPERM/SIGTRAP으로 실패했다. 포트 없이 Playwright route로 정적 빌드를 제공하는 시도도 Chromium 실행 단계에서 실패했다. 화면 실측 결과나 스크린샷은 없다.

### 세션 B 실측 요청

R1에서도 실제 Chromium 실행은 `setsockopt: Operation not permitted` 뒤 `SIGTRAP`, Vite listen은 `EPERM 127.0.0.1:5179`로 실패했다. 브라우저 안전 설정을 바꾸거나 네트워크 제한을 우회하지 않았다. 실제 화면·스크린샷·낭독 결과는 없다.

- **1024×768 터치:** 긴 브리핑에서도 카드·44px 토글 5개가 스크롤 없이 보이는지, 항만 133점 선택, 오른쪽 나라 카드의 값·연도 줄바꿈, 출처 문구·자료 스크롤.
- **1366×768:** 거점·국가 휘장 겹침, 카드가 지도 밖에 있는지, 표 전환 초점·133항만/12지표 행 확인.
- **400% 확대:** 한 열 배치·가로 넘침·토글·브리핑·닫기 접근, 길어진 출처·값·연도의 가독성.
- **화면 낭독:** 열기 단추 dialog 안내, dialog 제목·Tab 순환·Escape 후 초점 복귀, 토글당 한 번 낭독, 브리핑 status와 표 caption, 지표별 2025년·2022년.
- **reduced-motion:** 스캔라인 없음·비네트만 있음·이동 클래스 없음·기존 지도 애니메이션 정지. 글자 대비도 실제 빌드에서 측정.

### 알파 관찰 항목

“지연 항만을 본 뒤 다음 계약의 도착 항을 바꾸는가”. 지도·브리핑에서 본 근거와 선택 이유를 함께 관찰한다. 국가 지표에서 **2025년 무역 수치와 2022년 물류성과지수의 기준 연도가 다름을 읽는가**, 야간 불빛을 경제 규모의 직접 측정값으로 오해하는가도 관찰한다. 사람 관찰은 아직 실행하지 않았다.

### 범위 밖 발견

1. 연구 파일 두 개가 작업 HEAD에 없다. 이번에는 이미 로컬에 저장된 연구 브랜치의 지정 blob을 읽어 완료했지만, 허브는 원문 근거를 개발 브랜치에도 함께 보존해야 한다.
2. 항만 원자료에는 국가 칸이 없다. 25 km 대응 게임 거점 밖의 나라 칸은 1차처럼 ‘확인 전’이다. 이름 자료만으로 국적을 추정해 채우지 않았다.
3. NASA SVS와 Earth Observatory 배포본의 이용 조건 동일 여부는 미확인이다. pending을 유지했다.
4. 환경 제한 때문에 터치·확대·화면 낭독·대비의 실제 측정은 세션 B에서 필요하다.
