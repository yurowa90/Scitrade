### 손 계산·고정물

- 공개 일정은 자료의 `(firstDay, intervalDays, lastDay, validDays) = (1, 7, 78, 3)`을 읽는다. 8일에서 결제일 15일이면 `(8,15] = {15}`로 1회다. D15의 30일까지는 `{15,22,29}`로 3회, D30의 45일까지는 5회다. 100일 이후 결제일도 마지막 공개일 78에서 끝나 `(78−15)/7+1 = 10회`다.
- 잠김 비율: 가용 1원·미수 2원은 `20000 ÷ 3 = 6666 나머지 2`, `2×2 ≥ 3`이므로 6667 bp. 가용 31원·미수 1원은 `10000 ÷ 32 = 312 나머지 16`으로 정확히 절반을 올려 313 bp. 분모 0·음수는 null이다.
- 시작 자금(4.1-4가): 시드 **2001**, 8일까지 명령 없이 진행. USD 분개는 day 0 `OPENING-USD` 하나뿐이다. `r(0)=1300`, `r(8)=1291`, USD 300000센트이므로 `3,873,000−3,900,000 = −27,000원`이다.
- 비용·반올림(4.1-4나·5): 시드 **2001**, 8일 환율 1291·15일 1282. 8일 분개에 3센트 비용 두 줄, 15일 분개에 3센트 비용 한 줄을 `post`로 추가했다. `round(38.73)+round(38.73)+round(38.46)=39+39+38=116원`. 모두 마감일 환율이면 `38×3=114원`, 같은 날 합친 뒤 환산하면 `round(77.46)+round(38.46)=77+38=115원`이다.
- 수익·감액·자본도 추가 검산: 8일 USD 수익 13센트→168원, 감액 2센트→정상 잔액 −26원, 환전 자본 17센트→219원. 각 경우 자산−부채=자본+수익−비용+환율 변동 손익이 원 단위로 맞는다. FX 층을 끈 명령 없는 상태는 차이가 0이다.
