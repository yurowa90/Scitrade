## 질문

작업 지시서는 시험의 **“기대값 줄(값만, 시험 의도는 바꾸지 않는다)”**만 수정하도록 제한한다. 그래서 위 회귀 시험 하나에 변경 전 시장 조건을 고정하는 설정을 추가할 수 있는지 확인을 요청했다. 확인 답변이 없어 작업 트리에 적용하지 않았다. 이 파일의 기대값을 거절로 바꾸거나 시험을 빼서 통과시키지 않았다.

검토 가능한 수정안은 아래와 같다. 사본에서 이 설정만 적용하면 `src/engine/m2a5-warehouse.test.ts` 13시험이 기존 기대값 그대로 통과했다(로그 `/tmp/TASK-0032-warehouse-proposal.log`, 패치 `/tmp/TASK-0032-warehouse-proposal.patch`).

```ts
// 과거 차단 기간 결함을 재현한 시장 조건을 이 시험 안에서 고정한다.
const cfg = structuredClone(config), policy = policyById('MAX_CONTRIBUTION~inv:SE~hire:2pt@30')!;
cfg.seed = 1001;
cfg.operations!.market.trade.maxLotsChoices = [1, 2, 3];
const salePrices = [1400, 4900, 1350, 5000];
cfg.operations!.market.rows.filter((r) => r.side === 'SELL').forEach((r, i) => { r.basePriceMinor = salePrices[i]!; });
```

J4 초과와 나머지 균형 판정의 후속 결정은 세션 A 검수에 넘긴다.
