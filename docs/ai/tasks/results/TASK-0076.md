## 조합 탐침과 관문 판정

0075 10가와 같은 AST 값 import/재수출 닫힘도 사본에서 확인했다. D의 새 네 파일, B의 `save-shape.ts`, C의 `market_rules.json`·자료 진입 모듈은 각각 main 정적 닫힘 밖이다. D+B+C에서도 이 대상들이 모두 밖이다. A′는 `operations-invariants-core.ts`에 복사된 **사용하지 않는 값 import** 때문에 `operations.ts`가 정적 닫힘에 남는다. 빌드에서는 제거되어도 R1 4.6의 원천 검사를 통과하지 못하므로 A′를 선택한다면 이 import 정리와 크기 재측정이 추가로 필요하다. A′ 수치를 완성된 분리의 수치로 보지 않는 또 하나의 이유다.

위험 순서 **D < B ≈ C < A′**를 적용했다. C 단독이 B보다 74 B 더 줄지만 차이가 작고, B는 자료 로더·시나리오 제목을 건드리지 않아 D→B→C를 주 비교 순서로 썼다. 동률 범주의 최소 부분집합 B+C와 반대 순서 D+C도 함께 쟀다.

## 범위 밖 발견

- `rolldown/utils`는 vite의 설치된 하위 의존성이다. 직접 의존성으로 선언되지 않은 문제(STATUS 후속)는 이번에 수정하지 않았다. 재현 스크립트는 설치된 rolldown 1.2.12 파서를 사용하며 새 설치가 없다.
- M1 `title_ko` 부재와 rules2 골든의 marketTable 재수출은 R1 설계/이동 목록에 반영할 사항이다. 데이터·골든 기대값을 바꿀 사유가 아니다.
- 탐침만으로 등록 순서·오프라인 재시도·함수 분리의 상태 동일성을 증명할 수 없다. 제품 코드 변경이 승인되면 지시된 검증을 별도로 실행해야 한다.
