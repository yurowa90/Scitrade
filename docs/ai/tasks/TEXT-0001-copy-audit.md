# TEXT-0001 게임 문구 점검(읽기 전용): 학생이 보는 한국어 문구의 문제 목록

- **지위: 승인(허브, 2026-10-23).** 문구 담당 줄(세션 T → Antigravity CLI `agy`)의 첫 지시서다.
- 실행 모델: `agy --model gemini-4-argon-medium`(Gemini 4 Argon, 추론 보통). 사용자의 구글 AI 울트라 구독으로 돈다.
- 실행: `tools/ai/agy_task.sh docs/ai/tasks/TEXT-0001-copy-audit.md`(세션 T가 만든다). 한 번에 하나씩 돌린다.
- 결과 파일: `docs/ai/tasks/results/TEXT-0001.md` 하나뿐이다. **이 작업은 어떤 문구도 고치지 않는다.**

## 목적

고칠 문구를 정하기 전에, 지금 학생이 화면에서 읽는 한국어 문구의 문제를 근거와 함께 모은다. 그다음 지시서(TEXT-0002~)는 허브가 이 목록을 검토해 우선순위를 정한 뒤 쓴다.

## 읽을 범위

- 화면 문구: `src/ui/**/*.ts` 안의 한국어 문자열 리터럴. 시험 파일(`*.test.ts`)은 뺀다.
- 자료 문구 가운데 학생에게 보이는 칸: `data/events.json`(`title_ko`·`label_ko`·`tradeoff_ko`), `data/culture_activities.json`(`title_ko`·`observations_ko`), `data/contacts.json`(`role_ko`), `data/market_rules.json`(`title_ko`·`name_ko`).
- 이미 사용자가 승인한 문장은 `docs/ai/design/BUSAN-approved-texts.md`에 있다. 이 문장들은 지적 대상에서 빼고, 문체 기준으로만 참고한다.

## 점검 기준(이 순서로 중요)

1. **사실 오류 가능성**: 무역 용어(인코텀즈, 운임, 관세, HS, 환율, 결제 방식, 매출채권)를 잘못 쓰거나 실제 제도와 다르게 읽히는 문장. 게임 안 가상값이라는 표지(가상·설계값)가 빠진 곳.
2. **학생 이해도**: 고등학생(일반계·특성화고)이 처음 보는 용어를 풀이 없이 쓴 곳. 한 문장이 너무 길거나 주어가 빠져 뜻이 모호한 곳.
3. **일관성**: 같은 개념을 여러 이름으로 부르는 곳(예: 수금·입금·대금 회수). 존댓말과 반말이 섞인 곳.
4. **금지 사항**: 실명 기업·브랜드·선박명, KOTRA·KITA 업무를 흉내 내는 표현, 주한미군·매립지 분쟁·보부상 국적 같은 민감 소재, 특정 개인을 겨냥한 문장.
5. **분량·배치 위험**: 1024px 화면 머리 줄·버튼·표 칸에 들어가기에 지나치게 긴 문구(추정이면 ‘추정’으로 적는다).

## 결과 파일 형식

`docs/ai/tasks/results/TEXT-0001.md`에 다음을 쓴다.

1. 요약: 기준별 지적 수, 가장 시급한 5건.
2. 지적 표: `| id | 기준(1~5) | 파일:줄 | 원문(그대로) | 문제 | 고친 문장 제안 | 확신(높음/보통/낮음) |`
   - 원문은 한 글자도 바꾸지 않고 옮긴다.
   - 사실 판단(기준 1)은 근거를 적는다. 근거가 없으면 확신을 ‘낮음’으로 두고 ‘확인 필요’라고 쓴다. 근거를 지어내지 않는다.
3. 용어 대조표 초안: 같은 개념에 쓰인 여러 이름과, 하나로 통일할 후보.
4. 다루지 못한 범위: 너무 많아 건너뛴 파일이 있으면 숨기지 말고 적는다.

## 하지 않는 것

- 저장소의 어떤 파일도 고치지 않는다. 결과 파일 하나만 만든다.
- 웹 검색 결과를 근거처럼 쓰지 않는다. 사실 판단이 필요하면 ‘확인 필요’로 남긴다.
- 지적은 300건을 넘기지 않는다. 넘으면 기준 1·2·4를 먼저 채운다.
