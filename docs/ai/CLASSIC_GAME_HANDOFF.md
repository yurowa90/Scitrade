## 2. 유지할 목적과 근거

**동료와 함께 성장하고 세계의 도시·문화·사람을 알아가며, 무역회사의 돈·시간·인력·환경을 근거로 판단하는 게임**이라는 목적을 유지한다. 발견과 관계를 모두 수익 보너스로 환원하지 않는다. 기준 작품은 대항해시대 IV·더 길드 3이고, 에어 매니지먼트·캐피탈리즘·도서관·육성 게임은 필요한 판단 구조를 보완하는 자료다.

- 에어 매니지먼트 2: 항로 성과와 회사 전체 손익, 선지출과 나중에 얻는 운송능력의 시차.
- 베스트 라이브러리 리런: 수요·용량·이용률, 즉시 지출과 턴 후 변화. 여러 투자를 함께 한 초반 기록이므로 개별 투자 효과는 미확정.
- 캐피탈리즘 2: 공식 매뉴얼의 병목 진단·전문화/다변화·요약에서 상세와 행동으로 연결. 기존 플레이는 메뉴·설정까지이므로 본게임 실증이라고 쓰지 않는다.
- PM2·심시티·문명 기록: 시간 배분과 성장, 연결과 확장. 원작의 계수나 장기 우위를 그대로 전용하지 않는다.

출처·확인 범위와 적용표는 [CLASSIC_GAME_INSIGHTS](../CLASSIC_GAME_INSIGHTS.md) 2~3절에 있다. 이번에 원작을 재플레이하거나 학생 효과를 측정한 것은 아니다.

## 5. 첫 구현 단위의 완료 조건

TASK-0012의 기존 장면 기준·의무 항목이 우선이다. 아래는 CL-05·07을 그 기준과 연결한 확인 목록이다.

1. 화면·기록장을 열고 닫기만 해서는 날짜·현금·보상이 변하지 않는다. M1 등 `config.culture`가 없는 시나리오에는 문화 기능이 나오지 않는다.
2. 활동 선택 전에 업무 공백·비용·원화 여유·급여 가능일·새 기록과 바뀌지 않는 값을 읽을 수 있다. UI가 엔진의 허용 여부나 문구를 별도로 만들어 모순을 일으키지 않는다.
3. 예정/확정, 회사의 첫 보고/직원의 직접 경험/함께한 활동을 구분한다. 기록·경험치를 화면 열기나 저장·불러오기로 중복 지급하지 않는다.
4. 결과의 네 줄(알게 된 점·범위·말하지 않는 것·아직 모르는 것)을 읽고 기록장에서 다시 찾을 수 있다. 한 인물의 말을 도시·국가 전체의 성향으로 일반화하지 않는다.
5. 문화 기록과 직원 경험이 가격·처리량·관세·운임·거래 신뢰를 자동 증가시키지 않는다. 일반 훈련의 현재 처리량 불변도 유지한다.
6. 문화 장면이 기존 T1→T3→T2→T4→T5의 첫 행동·확정 흐름·알림·초점을 방해하지 않는다. 화면 읽기와 키보드 경로를 확인한다.
7. 학생 검토에서는 기회비용 설명과 함께 다시 알아보고 싶은 인물·장소·질문을 묻는다. 점수를 올렸다는 것만으로 재미·학습 효과를 통과 처리하지 않는다.

## 6. 검증과 결과 보고

**이 문서 인계에서 수행할 검사:** 자료 manifest 갱신, `python3 tools/validate_data.py`, 변경 문서의 상대 링크, `git diff --check`, 문서 외 변경 없음 확인. 엔진 테스트·브라우저·학생 실험 통과로 대신 표현하지 않는다.

**후속 구현 시:** 작업의 위험에 맞는 기존 테스트와 필요한 검증을 실행한다. WORKFLOW의 `tools/ai/review_checks.sh`를 기준으로 자료·타입·테스트·빌드 결과를 구분한다. 저장 전후 재현, 기존 금액·경험치·처리량의 불변, 중복 실행·업무 시간 충돌을 해당 변화에 맞게 확인한다. 화면 작업은 직접 조작해 확인한다.

- 기기: 기존 시험 계획과 TASK-0012 장면 기준을 따른다. 이전 비교 크기 1366×768·1280×800·1180×820·1080×810과 장면 기준의 추가 크기를 구분해 기록한다.
- 브라우저: 가능하면 Safari를 포함한다. 데스크톱 화면 크기 재현과 실제 iPad 터치 검증을 구분한다.
- 사용자 검토: 최초 견적 찾기, 병목 설명, 비용·시점 판단, 동료·문화 기억을 관찰한다. 자동 검사 통과를 학생 효과로 일반화하지 않는다.

결과는 기존 `docs/ai/tasks/results/` 형식으로 변경 파일·대상 빌드·실행 검사·남은 항목을 적는다. Claude 총괄 검수 뒤 STATUS·DECISIONS·작업 목록을 실제 결과에 맞게 갱신한다. 시험 빌드의 동결·배포 절차는 별도로 유지한다.
