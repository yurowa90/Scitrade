## 2. 60초 뒤 학습자가 말할 수 있어야 하는 것 (학습 증거)

1. **관찰 ≠ 일반화:** “윤서 한 사람이 작은 묶음을 원한다고 했을 뿐이다. 부산 상인 모두가 그렇다는 뜻은 아니다.”
2. **아직 모르는 것:** “더 알려면 원하는 묶음 크기·수량, 그런 규격을 이미 공급하는 곳이 있는지 확인해야 한다.”
3. **기회비용:** “이 활동은 그 직원의 하루 업무와 원화 20,000원을 쓴다.”
4. **바뀌지 않는 것:** “활동을 해도 가격·하루 처리량·거래 신뢰는 바뀌지 않는다.” (사용성 시험 Q6 오개념 대비)

확인 방법(2차 확인 때): 결과 카드를 본 직후 “방금 알게 된 것을 한 문장으로 말해 보세요”, “이걸로 부산 손님 전체에 대해 말할 수 있나요?”를 묻고 1·2를 채점한다.

## 4. 시안이 함께 보여야 할 TASK-0012 의무 항목

- RF-1: 캠페인 마지막 날을 넘기는 활동은 미리 보기에서 표시(지금 자료는 모두 1일이지만 화면 규칙은 둔다).
- RF-2: ‘새로 생길 기록’은 시작이 허용될 때만 보인다.
- 원화 보고서의 ‘현지 활동비’ 행.
- 급여 미지급 관련 문구, P0-CITY-01 화면 단언 2개(열기·닫기로 상태 불변, 금융센터 미구현 표시).
- `config.culture`가 없는 시나리오(M1)에는 아무것도 보이지 않는다.
- 엔진이 만든 문구(조사 포함)를 화면에서 다시 만들지 않는다.
