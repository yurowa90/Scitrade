## 5. 지급 경고 + 대기열일 때 위쪽 막대

- **상태 만드는 법:** 규칙 2에서 다음 순서를 밟는다.

  2. 2일 KRW→USD 21묶음(최대) → 하루 진행
  3. 3일에 ‘경고 · 실패까지 13일’이 된다.
  4. 여기서 USD→KRW 1묶음을 오늘 할 일에 넣으면 ‘하루 진행 뒤 예상: 경고 · 실패까지 13일’ 줄이 붙는다.

## 6. 사용성 판단거리 (결함 아님, 세션 A 판단)

1. **운영 지표 칸이 0034 전보다 2.6배 길다(1024px +1,640~1,760px, 1366px +1,400~1,480px).**
   - 넘침은 없다. 그러나 1024px 세 열에서는 297px 폭 칸에 2.7천 px가 쌓여, 화면 높이 700px 기준 약 4화면이다.
   - 투자 구역만 700px 남짓이다.
   - 고칠 방향(택1, 측정은 R1 빌드에서 다시):
     - 투자 구역을 접힌 `<details>`로 둔다. 이미 계약·예정인 항목은 요약 한 줄로 둔다.
     - 또는 본사·창고 구역을 경영 보고 밖의 넓은 칸으로 옮긴다.
2. **경고 상태에서 막대 높이가 정상보다 최대 17px 높다(1001~1024px).**
   - 막대 높이를 쓰는 펼침 띠·읽던 자리 보정은 실제 막대를 재므로 동작은 맞을 것이다.
   - 다만 TASK-0024 측정의 막대 아래 끝 기준값과는 경고 상태에서 다르다.
   - 지급 상태 칸에 최소 폭을 주거나 예상 줄을 `title`로 옮기면 정상 높이를 지킬 수 있다. 받아들여도 되는 크기라고 본다.
3. **(참고) 경고 상태를 만드는 길에서 본 것.** 1일에 KRW→USD 50묶음을 넣어도 환전 칸이 막지 않는다. 그날 급여 가능일은 56일에서 18일로 줄 뿐이다. 2일에 21묶음을 넣으면 ‘오늘 급여·임차료를 다 낼 수 없다’는 문장이 나오지만, 명령은 들어간다. 그 결과 3일에 경고가 된다. 의도한 설계(경고로 배우게 함)인지 세션 A 확인이 필요하다.
