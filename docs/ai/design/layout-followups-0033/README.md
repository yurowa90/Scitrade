# TASK-0033 레이아웃 후속 3건: CSS 고침 시제품과 실측 (세션 B, 2026-10-13)

[TASK-0033 측정 기록](../task0033-chromium/README.md) 6절의 후속 후보 3건을 고치는 CSS를 미리 만들고 Chromium으로 쟀다. 허브는 1번을 세션 A의 TASK-0034 후보로 넘겼고, 2·3번은 다음 화면 지시서에 한 줄씩 붙이기로 했다(2026-10-13). 이 문서는 그 지시서에 그대로 넣을 수 있는 고침과 근거다. 화면 파일은 세션 A가 잠그고 있어 세션 B는 고치지 않는다.

## 고침 (`style.patch`, `src/ui/style.css` 세 줄)

| 후보 | 지금 | 고침 |
|---|---|---|
| 1 (중) iPad mini 1024px 시세표 가로 넘침 36px | `.market-table table { min-width: 42rem; }` | `min-width: 39rem` |
| 2 (하) 1001~1023px 규칙 2 막대 두 줄 | `@media (min-width: 1024px) { .operations-statusbar { flex-wrap: nowrap; … } }` | 같은 규칙을 `min-width: 1001px`부터 |
| 3 (하) 768px 하루 진행 위치가 규칙별로 다름 | `.queue-chip + .day-action { margin-left: 0; }` | 같은 규칙을 `@media (min-width: 1001px)` 안에만 |

3번의 원인은 flex 줄바꿈이다. 1000px 이하에서 막대가 두 줄이 되면 규칙이 다르게 작동한다.
- 규칙 1은 ‘오늘 할 일’ 칩이 첫 줄 오른쪽에 남는다. 그리고 `margin-left: 0`인 ‘하루 진행’만 둘째 줄 왼쪽으로 내려간다.
- 규칙 2는 칩도 둘째 줄로 내려가, 칩의 `margin-left: auto`가 둘을 함께 오른쪽으로 민다.

고친 뒤에는 1000px 이하에서 ‘하루 진행’이 자기 `margin-left: auto`로 줄 끝에 선다. 1001px 이상에서는 지금처럼 칩 바로 오른쪽이다.
