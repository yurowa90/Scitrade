# 상황실 지도 1판(10b-1) 정적 모형 (세션 B, 2026-10-14)

허브 요청(2026-10-14)으로 TASK-0061 지시서 전에 만든 정적 모형이다. 범위는 [제작 계획](../production-plan-2026-10-14/PLAN.md) ‘상황실 지도 1판(10b-1) 범위’다.

**이것은 구현이 아니다.** 지금 개발 빌드(`17c731c`) 위에 덧씌운 시안이다.

- 게임이 그린 지도 SVG를 복제하고 층을 얹어 Chromium으로 찍었다.
- 저장소 코드(`src/`)는 바꾸지 않았다.
- 버튼은 눌러도 동작하지 않는다.
- 국가 지표 값은 모두 자리표시(‘—’)다. 모든 자료의 라이선스 판정은 세션 C 대조 전이라 ‘확인 전’으로 표시했다.

## 1. 화면

모든 화면의 게임 상태는 같다. 시나리오 ‘M1 거래 한 건 — 항만 지연 사례’에서 견적을 받고 운송편을 예약한 뒤 8일까지 진행했다. 이때 화물선 1척이 운항 중이고, 하이퐁 도착이 7일에서 9일로 늦어진 상태다.

| 파일 | 크기·입력 | 보기 |
|---|---|---|
| `ipad-all.png` | 1024×768 터치(iPad mini 가로) | 자유 탐색, 레이어 5개 모두 켬 |
| `chromebook-all.png` | 1366×768 마우스(크롬북) | 자유 탐색, 레이어 5개 모두 켬 |

- iPad 화면은 2배 배율로 찍은 것을 1배로 줄여 200색으로 저장했다. 저장소 무게 때문이다.

- 머리 줄:

  - 레이어 토글 5개

**시각 모드(`mock/situation.css`).**

- 정지한 스캔라인(3px 간격, 3.5% 밝기)과 가장자리 비네트뿐이다. 원본 443 B, gzip 277 B다.
- 움직임이 없으므로 깜빡임도 없다.
- `prefers-reduced-motion`일 때는 스캔라인을 빼고 비네트만 남긴다. 정지 무늬도 줄무늬 민감 사용자에게 부담일 수 있어서다.
- 군사·감시 톤 요소(조준선, 탐지 상자, 열화상·야간투시 색, 타임코드)는 넣지 않았다.

## 2. 크기 추정

| 항목 | 바이트 | 비고 |
|---|---|---|
| 야간 불빛 PNG(4단계) | 17,166 | 3단계 13,519, 6단계 17,295, 8단계 17,448(첫 시험값). PNG는 gzip으로 더 줄지 않는다 |
| 항만 자료(이름·경도·위도·등급, 135곳) | 3,925(gzip 약 1.8 KB) | 지도 범위 안만 |
| 시각 모드 CSS | 443(gzip 277) | |
| 모형 코드(`mock/mock.js`) | 8,920(gzip 3,706) | 구현 코드 크기의 거친 대리값 |
| **지연 청크 합(추정)** | **gzip 약 6~8 KB + PNG 17 KB** | 코드·항만·국가 카드 자료(약 1 KB)·CSS |

- **첫 화면 무영향 확인 방법:** TASK-0059와 같다. 상황실 화면을 `lazyScreen`으로 따로 묶는다.
  - `node tools/check_bundle_size.mjs dist`에서 새 청크가 ‘나중에 받음’으로 나와야 한다.
  - 첫 화면 gzip이 기준과 같아야 한다(현재 124,796 B, 빌드 표시 `dev`).
  - PNG는 상황실을 열 때만 받는다. `index.html`과 첫 화면 CSS에 PNG 주소가 없어야 한다.
- **미리 받기:** 첫 화면 뒤 한가할 때 코드만 미리 받는다. PNG(17 KB)는 상황실을 열 때 받는 쪽을 권한다. 교실 회선에서 아무도 열지 않는 화면의 그림까지 받을 이유가 없다.
- **세계지도(2장)판 야간 불빛:** 세계 논리 격자는 1800×610이다. 면적이 동아시아의 약 3.3배라 PNG도 50~60 KB로 예상한다(재지 않음). 1판 범위 밖이다.

## 3. 판단거리 (허브·사용자 확인용)

1. **야간 불빛을 켜면 중국 내륙이 빽빽해져 게임 거점 이름표가 덜 보인다.**
   - 경제활동 대리지표로서 ‘연안이 밝다’는 점은 잘 보인다. 한국, 상하이 일대, 주강 삼각주가 두드러진다.
   - 다만 기본으로 켜면 정보가 너무 많다.
   - 권고: 자유 탐색의 기본값은 끈다. 브리핑에서는 켜지 않는다. 사용자가 켤 때 불빛 단계 범례(4단계)와 NASA 크레딧을 지도 아래에 보인다.
2. **국가 카드가 지도를 가린다.**
   - 1366에서 한국 카드가 부산 이름표를 가렸다.
   - 권고: 구현에서는 카드를 지도 위 고정 자리 대신 오른쪽 칸 아래(또는 ‘표로 보기’)에 둔다. 지도에는 국가 이름 휘장만 둔다.
   - 1024 터치에서는 오른쪽 칸이 272px라 카드 3장을 세로로 쌓으면 스크롤이 생긴다. 실측 대상이다.
3. **항만 135곳 이름을 지도에 쓰면 게임 거점 이름(한국어)과 겹치고 영어가 섞인다.**
   - 첫 시안에서 그랬다(‘Shanghai’와 ‘상하이’).
   - 권고: 항만은 점만 찍는다. 이름은 누르기·‘지도에서 볼 곳’·표에서 한국어 표기로 보인다. 한국어 표기 135곳을 누가 만들지(자료 작업)는 허브가 정한다.
4. **브리핑 확대 배율.**
   - 처음에는 300×220 지도 단위로 확대했는데, 이름표가 화면의 1/3을 차지했다.
   - 560×400으로 넓히고, 지도 범위 밖으로 나가지 않게 잘랐다. 구현에서는 사건 위치와 도착 항만이 함께 들어오는 최소 영역을 쓰는 것이 낫다.
5. **‘껍데기 화면’ 위험.**
   - 1판에서 게임 상태와 이어진 층은 ①·②와 브리핑뿐이다. ③~⑤는 배경 자료다.
   - 학생이 이 화면에서 결정을 바꿀 근거를 얻는지가 알파의 관찰거리다. 예: 지연 항만을 보고 다음 계약의 도착 항을 바꾸는가.

## 4. 접근성 메모

- **레이어 토글:**
  - 실제 `<input type="checkbox">`와 `<label>`이다. 칸 높이는 40px 이상(터치 44px 목표)이다.
  - 켜고 끌 때 `#live-status`에 ‘야간 불빛 켬’처럼 한 번 낭독한다.
  - 지도 SVG의 `aria-label`도 켠 층을 반영해 바꾼다.
- **프리셋:** 두 단추 묶음(`role="group"`, `aria-pressed`)이다. 브리핑으로 바꾸면 초점이 브리핑 카드 제목으로 간다.
- **사건 브리핑:**
  - 카드는 `role="status"`로 사건 문장을 낭독한다.
  - ‘이전 / 다음 사건 / 브리핑 끝내기’는 키보드로 닿는다.
  - 지도 이동은 `prefers-reduced-motion`이면 애니메이션 없이 바로 바꾼다.
- **표로 보기(필수):** 지도에만 있는 정보를 표로도 준다.
  - 표 1: 운항 중 화물(계약·항로·출발·도착 예정·지연 이유)
  - 표 2: 항만(이름·나라·게임 거점 여부)
  - 표 3: 국가 지표(값·기준일·출처)
  - 야간 불빛은 표로 옮길 수 없다. 그래서 ‘이 층은 경제활동이 많은 곳을 밝게 보이는 그림입니다’라는 설명 문장과 출처를 둔다.
- **상황실 화면(스캔라인)은 대비를 낮춘다.**
  - 글자 대비 측정은 구현 빌드에서 한다.
  - 꺼 두는 선택지가 머리 줄에 있다.
- **대화상자:** 모형은 전체 화면 `role="dialog"`, `aria-modal="true"`다.
  - 기존 지도 칸(`map-detail`)의 Escape·초점 복귀 규칙을 따른다.
  - 닫으면 ‘상황실’ 열기 단추로 초점이 돌아온다.

## 5. 자료 출처(모형에 쓴 것, 라이선스 판정은 세션 C)

- **Natural Earth `ne_10m_ports`:** v5.1(`naciscdn.org`). 저장소에는 지도 범위 안 135곳의 이름·경도·위도·등급만 `data/ports-ea.json`으로 두었다.
- **NASA Earth Observatory Black Marble 2016:** 0.1° 회색 GeoTIFF(`BlackMarble_2016_01deg_gray_geo.tif`)다. 저장소에는 줄인 `data/nightlights-ea.png`만 두었다. 원본은 저장소 밖에서 받았다.
- **World Bank WDI:** 값을 받지 않았다(자리표시).
- 모형 자료는 게임에 들어가지 않는다. 구현할 때 세션 C가 license_tier·retrieved_on을 정한 스냅숏으로 다시 들인다.

## 6. 재현

- `harness/ports.py <압축 푼 폴더> <출력.json>`: Natural Earth 항만을 지도 범위로 거른다.
- `harness/nightlights.py <Black Marble tif> <출력.png>`: 야간 불빛 PNG를 만든다.
- `harness/smshot.js`: 게임 상태를 만들고 `mock/mock.js`를 얹어 네 장을 찍는다. 저장소 밖 `kb/blib.js`를 쓰고, 빌드는 `17c731c`(빌드 표시 `dev`)다.
