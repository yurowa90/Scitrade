**키보드 사용자에게 초점이 사라져 보이는가**

- 루트는 포인터로 누를 때만 초점을 받는다. Tab 순서에는 없다.
- 그 상태에서 다음 Tab은 곧바로 첫 단추로 가고 테두리가 보인다. 그래서 키보드만 쓰는 사용자가 초점을 잃는 경로는 찾지 못했다.
- 포인터로 누른 직후에 테두리가 없는 것은 다른 요소들과 같은 `:focus-visible` 규칙이다.

## 3. 초점 순서

- 선택 정보 제목에서 Shift+Tab을 누르면 머리 줄 마지막 단추 ‘닫기’로 간다. 문서 순서상 바로 앞이다. R2에서는 마지막 토글로 건너뛰었다.
- 선택 정보 제목에서 Tab을 누르면 근처 목록 첫 단추로 간다.
- 근처 목록에서 고르면 초점이 선택 정보 제목으로 가고 제목이 ‘광저우’로 바뀐다.
