폴더

- h/ : 측정 스크립트(accept24/remeas2에서 복사, DISTS만 바꿈) + qpos.js(오늘 할 일 위치·Tab 수) + mq.js(1180↔1000 창 크기 바꿈) + sum.py(요약).

시안
- O1  style.css 한 열 격자만 화면 코드 순서로: "trade" "crew" "resources" "queue" "world" "report" "log".
- O2  main.ts 패널 화면 코드 순서를 한 열 보이는 순서로: 거래 → 오늘 할 일 → 동료 → 자원 → 보고 → 지도 → 기록(세 열 격자는 그대로).
- O3a style.css .layout에 reading-flow: grid-rows (Chromium 137+만. 측정 Chromium 141).
- O3b main.ts가 matchMedia('(max-width: 1000px)')로 한 열이면 O2 순서, 아니면 지금 순서로 그림. 바뀌면 다시 그림.
- O3b2 O3b + 다시 그릴 때 같은 조작에 초점 유지(preventScroll). 권고안 코드.
