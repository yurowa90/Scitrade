- **창 폭 전환 완료 조건 — 받되 더 엄격하게.** 초안이 1180px으로 되돌린 뒤를 뺀 이유는 맞다. 기준과 다른 까닭은 폭 전환이 아니라 그 사이의 Tab(기준은 지도 단추로 건너뛰며 쪽을 굴림)이다. 그래서 Tab 없이 왕복하는 대조를 더 쟀다. 일정 단추·동료 필터 두 초점 모두 세 단계(1180 → 1000 → 1180)의 초점·단추 위치·`scrollY`가 기준과 같았다. 완료 조건 5에 ‘Tab 없이 왕복하면 세 단계 모두 같음’을 넣고, Tab을 끼운 경우만 되돌린 뒤 위치를 기록으로 둔다. 측정기는 저장소 밖 `kb/mq.js`에 `TAB` 환경 변수를 더한 판이다.
- **`window.matchMedia` 존재 확인 예외 — 고침(예외 없앰).** 예외의 근거는 ‘지도 연결 시험 틀이 TASK-0025 파일이라 손댈 수 없다’였다. TASK-0025가 병합되어 `src/ui/*`는 세션 B 몫이 됐으므로 근거가 사라졌다. ‘시험 환경을 피하려고 존재 확인을 넣지 않고 시험 틀을 넓힌다’(TASK-0014 검수 기록) 규칙을 그대로 지키도록 `map-integration.test.ts` 29행 `window` 흉내에 `matchMedia` 하나를 더한다.
