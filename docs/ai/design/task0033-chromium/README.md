## 3. 환전 칸과 시세표

- **환전 칸:** 9개 프로필 × 3개 상태 모두 칸 밖 넘침 0, 조작 요소끼리 겹침 0, 쪽 가로 스크롤 0이다.
  - 1차의 금액 칸은 `input`이고 터치에서도 128×21px였다. 44px 규칙(`button, select, summary`)에 들지 않았다.
  - R2는 묶음 `select`라 터치 210×44px, 마우스 200×38.8px다.
- **시세표:** 표 최소 폭은 672px다.
  - ipadminiL(636px)과 p390(335px)에서 가로로 넘치고, 나머지 프로필에서는 넘치지 않는다.
  - R2 스크롤 칸: `role=region`, 이름 ‘시세표 (가로로 넘겨 보기)’, Tab으로 닿고 `:focus-visible`이 참이다. 외곽선은 solid 3px rgb(58,110,165), 간격 2px다.
  - 오른쪽 방향키 3번에 ipadminiL 36px(끝까지), p390 120px 움직인다.
  - Home·End는 표가 아니라 쪽 전체를 움직인다. 칸에 세로 넘침이 없을 때 Chromium의 기본 동작이다. 방향키로는 가로로 끝까지 갈 수 있다.
