**비판과 위험:** 위임은 ‘수락하면 자금, 배정하면 시간, 예약하면 선복이 묶인다’는 인과를 다시 가릴 수 있다(DECISIONS:230). 그래서 수락은 위임하지 않고, 위임한 명령을 ‘오늘 할 일’에 보인다. 자동 진행은 결과 알림을 건너뛰게 할 수 있다(DECISIONS:913의 ‘결과 보기를 누르지 않고 지나감’ 위험). 효과는 사용성 관찰로 확인한다.

### D12 도감 실루엣·직접 경험 표시 (B48)

**결정할 것:** 아직 만나지 않은 동료 칸을 보일지. 고용한 동료의 직접 경험을 어디에 보일지.

**근거:** 도감은 발견·합류·근무·교육 상태와 속성·직무 필터(UI_SPEC:62, DESIGN:1164). 미발견 후보는 어디에도 드러나지 않는다(DECISIONS:400). 해제 후보 버튼·‘다음 후보 n개’ 같은 계수기·점수 막대를 두지 않는다(DECISIONS:734). 수집 유도 문구를 빼고 ‘다녀온 직원’ 줄을 뺐다(DECISIONS:909·940). 그런데 영입 칸에는 이미 ‘미발견 후보 n명’이 보인다(`src/ui/recruitment.ts:121`).

**선택지:**

| | 내용 |
|---|---|
| **가 (권장)** | 실루엣 없음 유지. 고용한 동료의 ‘성장·훈련 상세’에 ‘직접 경험한 활동·지역’ 한 줄. 표 형태(직원 × 활동)는 만들지 않음 |
| 나 | 국가별 수첩에 ‘아직 만나지 않은 동료가 있습니다’ 한 줄(수는 보이지 않음) |
| 다 | 실루엣 + 만남 단서(60칸) |

**권장: 가.** 지금까지의 원칙(수집 순환 배제, DECISIONS:734·940)과 맞다. 다는 수집 욕구가 경영 판단을 끌고 갈 수 있고, 고용이 손해인 지금 경제(D03)에서 고용을 부추긴다. 실루엣 60종은 그림 일괄 제작(M5) 몫이라 지금 만들면 자리표시자가 된다. 학습 효과의 직접 근거는 찾지 못했다(설계 판단).

**덧붙임:** ‘미발견 후보 n명’ 표시는 DECISIONS:734의 계수기와 같은 성격이다. 가를 고르면 이 숫자를 ‘아직 조사하지 않은 장소가 있습니다’로 바꾸는 것을 기본값으로 한다.

**풀리는 항목:** PPL-06 일부, UX-38, CNT-03. 속성·직무 필터(UX-34)는 이 결정과 무관하게 진행한다.

**위험:** 배포 주소는 링크를 아는 누구나 열 수 있다(검색 제외만 건다, DECISIONS:800). 글꼴(D16)을 먼저 넣어야 재측정이 한 번으로 끝난다.

### D16 글꼴 내장 (B26)

**근거:** 페이지가 글꼴을 Google Fonts에서 불러와 접속 정보가 외부에 남는다. 연구로 발표하면 IRB 확인 때 적고, 필요하면 글꼴을 빌드에 넣는다(DECISIONS:806-809). 학교망에서 글꼴이 나오는지는 실기기 확인 항목이다(DECISIONS:899). `index.html:9-11`이 Gowun Dodum과 IBM Plex Sans KR을 외부에서 불러온다. 글꼴이 막히면 시스템 글꼴로 바뀌어 잰 배치와 달라진다(gap TPD-31).

**선택지:**

| | 내용 |

| **가 (권장)** | 지금 내장한다(평택판 재측정 전). 원본 글꼴 파일과 OFL 사본을 함께 넣는다. 크기가 크면 한글 부분 집합을 검토한다 |

**사실 확인:**
- 두 글꼴 모두 SIL Open Font License 1.1이다(Gowun Dodum: [산돌 구름 목록](https://www.sandollcloud.com/font/16934.html?lang=ko_KR), IBM Plex Sans KR: [Fontsource](https://fontsource.org/fonts/ibm-plex-sans-kr/about)·[Debian 저작권 기록](https://metadata.ftp-master.debian.org/changelogs/contrib/f/fonts-ibm-plex/stable_copyright), 검색 요약). OFL은 상업 이용·재배포를 허용하고 라이선스 사본 동봉을 요구한다.

**권장: 가.** 학교망 차단·측정값 흔들림·외부 접속 기록을 한 번에 없앤다. 평택판은 어차피 재측정하므로 지금 넣어야 측정이 한 번이다.

### D17 1차 사용성 시험: 날짜·참가자·IRB + 사후 질문 2개 (B15·B13)

**근거:** MVP 사용성 목표 ‘처음 접하는 5명 중 4명이 도움 없이 첫 계약 종결’(DESIGN:440). 사람 시험 단계(PLAN:34). 윤리 원칙(UT:143-151). 사용자가 정할 것(UT:155 날짜·참가자, UT:181 연구 발표 여부). 미검증 상태(STATUS.md:37). 표본 3~5명은 화면 문제를 찾는 근거이지 학습 효과 근거가 아니다(DECISIONS:757). 1차 시험은 고정 부산 3판(`a8ffa35`, DECISIONS:952). 사후 질문 후보 ‘누구와 어디를 다시 알아보고 싶은가’, ‘무엇을 바꿔 다시 해보고 싶은가’(CL:97-98). 지금 질문지에는 없다(UT:69-82).

**세부 결정:**

| 번호 | 선택지 | 권장 |
|---|---|---|
| D17-1 날짜 | 사용자 | — |
| D17-2 참가자 | 학교급·인원 | 5명. 학교급은 실제 수업 대상(통합사회 연결이면 고등학생) |
| D17-3 연구 발표 | 가 발표 가능성을 열어 둔다: 시험 전에 소속 기관 IRB 심의 또는 면제 확인, 보호자 동의·본인 동의. 1차 빌드(부산 3판 `a8ffa35`)는 Google Fonts·Netlify 접속 기록이 외부에 남으므로 신청서·동의서에 적는다(DECISIONS:806-809, UT:151). 글꼴 내장(D16)은 평택판부터다 / 나 수업 개선용으로만: UT 7절 원칙만 지키고 결과를 논문에 쓰지 않는다 | 가(조금이라도 발표 가능성이 있으면) |
| D17-4 사후 질문 2개 | 가 1차에 추가(약 2~3분) / 나 추가하지 않음 | 가 |

**권장 이유:**
- D17-2 5명: 목표 판정이 ‘5명 중 4명’이다(DESIGN:440). 다섯 명이 문제의 약 85%를 찾는다는 흔한 말은 문제 하나를 한 사람이 찾을 확률을 31%로 둔 모형 값이다(Nielsen & Landauer, 1993; [NN/g 해설](https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/), 검색 요약). 모의 실험에서 5명이 찾은 비율은 55~100%로 흔들렸다(Faulkner, 2003, 검색 요약). 그러니 5명은 화면 문제를 찾는 최소 단위로 보고, 결과를 일반화하지 않는다.
- D17-3 가: 시험 뒤에 연구 발표를 결정하면 사전 동의·심의가 없어 쓸 수 없게 될 위험이 있다. 사후 승인 가능 여부는 기관마다 다르다(이 문서에서 근거 미확인, 소속 기관 문의 필요). 심의 면제 요건도 법령 원문을 확인하지 못했다(국가법령정보센터 접속 차단). 면제 여부도 연구자가 아니라 IRB가 확인한다. 미성년 학생과 교사-학생 관계는 취약한 환경의 연구 대상으로 보아 면제가 어려울 수 있다. 소속 학교에 IRB가 없으면 국가생명윤리정책원의 공용기관생명윤리위원회(공용IRB, public.irb.or.kr)에 신청할 수 있는지 먼저 묻는다(대학 IRB 안내·공용IRB 보도, 검색 요약, 교사 연구의 신청 요건은 미확인).
- D17-4 가: 비용은 2~3분이다. 다만 3판에는 문화 화면이 없어 ‘다시 알아보고 싶은 인물·장소’ 답이 동료 중심일 것이다. 그 한계를 관찰지에 적는다.

**풀리는 항목:** TE-27, UX-25, TPD-25, B65(T5 해석), B14(2차 확인 설계).

## 이 문서의 간이 계산

- 62일 변화는 `payrollRunwayDay`와 같은 규칙(작업 공간 `s1b/runway.py`, 고정비·환전·고용 가정을 더함)으로 셌다. 8일·50일 고용, 22일 창고 확장, EV05·유료 조사·강화의 날짜는 runway.py에 없는 경우라 같은 규칙으로 따로 셌다. 임차료·환전·고용 경우의 날짜는 검수 때 엔진 `commitDay` 실행(임차료·환전은 장부 주입으로 흉내, 저장소 밖 임시 시험)으로 같게 나왔다. 22일 창고 확장 값은 청구 규칙이 미정이라 손계산이다.
- 20시드 표는 엔진이 아닌 간이 모형(`s1b/market_sim.py`, `s1b/final_table.py`)이다. 저장소에는 넣지 않았다. 모든 값은 간이 모형 추정(엔진 비교 실행기 TASK-0017로 다시 잰다)이다. 가정과 한계는 [M2A5 초안](M2A5-market-warehouse-draft.md) 7.3절에 있다.
- 검수 정정(2026-10-09): 원래 모형은 첫 미지급일을 한 번 정한 뒤, 미지급을 다 갚아도 지우지 않았다(`market_sim.py`의 `first_unpaid`). 그래서 갚았다가 다시 밀린 실행을 너무 일찍 실패로 셌다. D04 가의 정의(가장 오래된 미지급 의무의 발생일)로 다시 세어 H1(3/20 → 0/20)과 H2(51~77일 → 75~81일)를 고쳤다. 다른 행은 바뀌지 않았다. 재계산·민감도·창고 확장 변형 스크립트는 작업 공간 `accept22/s1b-verify/editor/`(`check.py`·`sens.py`·`expand.py`)에 있다. D03 나의 원 계산 스크립트는 남아 있지 않아 근사 재현 값으로 바꿨다.
