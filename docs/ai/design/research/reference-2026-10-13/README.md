## 방법

deep-research(ultradeep)를 따랐다.

1. 12개 영역을 병렬 수집했다.
2. 삼각검증 → 개요 조정 → 설계안 세 개(진화·재구성·새로 만들기)를 두 렌즈로 판정했다.
3. 절별로 집필한 뒤, 네 페르소나(무역 실무자, 교육공학 심사자, 구현 담당, 완결성 비평가)가 비평했다.
4. 빈칸 8개를 다시 수집했다(gap1~8). 저장소 실측(repo2)도 넣었다.
5. 모든 절을 보완했다.

게임을 직접 플레이한 결과가 아니다. 나무위키와 일부 팬 위키는 이 환경에서 열리지 않아 쓰지 않았다.

## 수치(원장 기준)

- 고유 출처 620개, 본문 인용 464개, 인용 근거 1,518개
- 판정한 사실 288건: 삼각검증 63건(약 22%), 단일 출처 90건(약 31%), 반박 4건
- 검증 도구:
  - validate_report: 통과
  - verify_citations: 비엄격 모드 통과. 링크 확인 실패는 대부분 405(HEAD 거부)와 일시 오류였다. 404 세 건은 GET으로 다시 열어 200을 확인했다.
  - verify_claim_support: 주장 327개 가운데 supported 182, partial 101, needs_review 35, unsupported 9. 사실 주장 211개 가운데 unsupported는 2개(0.9%)이고, 둘 다 이 조사 자체의 집계·사용자 방향에 관한 메타 문장이다.
