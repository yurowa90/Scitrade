# 경로 2 판정표 사전 커밋 (판본 1, 초안)

- 지위: **초안. 허브 승인 전.** 세션 A가 2026-10-14 허브 요청으로 썼다. 허브가 승인하면 이 문단을 '승인(날짜, 커밋)'으로 바꾸고, 그 커밋을 측정보다 앞선 기준 커밋으로 삼는다.
- 근거: `docs/ai/design/production-plan-2026-10-14/PLAN.md` 경로 2·3·4b·5, `docs/DECISIONS.md` ‘2026-10-14 제작 계획’·‘Q14’, `docs/ai/design/M2A5-SPEC.md` 17.3, `src/engine/sim/d03.ts`(J1~J7 현재 구현), `docs/ai/tasks/results/TASK-0032*.md`(현재 기준값).
- 손실 계약 비율의 목표대 5~25%는 허브가 전한 알파 품질 관문 D-19 권고다. 그 문서는 이 저장소에 아직 없다(`docs/QUALITY_GATE_ALPHA.md` 작성 전). 관문 문서가 들어오면 이 표의 수치와 맞는지 허브가 확인한다.

## 0. 규율

1. **측정 전 커밋.** 이 표가 들어간 커밋이 경로 5의 어떤 측정 실행보다 앞서야 한다. 경로 5 보고서는 이 커밋 해시를 첫 줄에 적는다.
2. **결과 뒤 기준 이동 0.** 측정 결과를 본 뒤 이 표의 판정 기준(문턱·비교 대상·시드 규칙)을 고치지 않는다. Q14(J4 상한 1.8배 → 2.0배)와 같은 사후 조정은 이 표 아래에서 금지한다.
   - 바꿔야 할 이유가 생기면 이 파일을 고치지 않고 `JUDGMENT_TABLE.v2.md`를 따로 커밋한다. 이유와 이 판본으로 낸 결과를 함께 적는다. v2로 다시 판정할 때는 **새 시드**(4절)를 쓴다.
3. **경제 손잡이는 바꿀 수 있다. 다만 미리 정한 것만, 정한 순서로, 정한 횟수 안에서만** 바꾼다(5절). 판정 기준과 경제 값은 다르다. 기준은 고정이고, 손잡이는 기준을 맞추려고 돌리는 것이다.
4. 판정마다 결과는 ‘통과·실패·진단(판정 아님)·해당 없음’ 넷 가운데 하나다. 실패도 값을 고치지 않고 그대로 보고한다(TASK-0029 원칙).

## 2. 비교 값의 정의

| 이름 | 정의 | 쓰는 곳 |
|---|---|---|
| USD 순자산 | 지금 `d03.ts`의 `usdAssets` | (가)·R0의 J1~J7(연속성) |
| **분석값** | USD 순자산 + KRW 순자산 ÷ `fx_krw_per_usd`(지금 1,300, 고정) | R1~R3과 (나)·(다)의 모든 판정 |
| **계약 실현 마진(원화)** | 직접 무역 계약 하나의 원화 기준 손익. 원화 줄은 그대로, 달러 줄은 **그 줄이 생긴 날의 참고 환율**로 바꿔 더한다(매입·운임·관세·부대비·클레임·수금). 회사 급여·임차료·환전 차감은 넣지 않는다 | 손실 계약 판정, J7 |
| 손실 계약 | 끝난 직접 무역 계약(완료·취소) 가운데 계약 실현 마진 < 0 | L1~L3 |

- **분석값에 고정 환율을 쓰는 이유:** 끝날 참고 환율로 바꾸면 마지막 주의 환율 운이 회사 비교를 흔든다. 고정 값으로 두면 환전으로 실현된 환차만 들어간다. 이 값은 설계 비교용이다. 게임 화면에 두 통화를 더한 값을 보이지 않는다는 SPEC 10.4 원칙은 그대로다.
- **계약 마진에 그날 환율을 쓰는 이유:** O1(환율 판단)이 가르칠 것이 바로 ‘거래일과 수금일 사이 환율 변화가 원화 이익을 바꾼다’이다. 회계에서 외화 매출채권의 환산 차이를 결제일에 인식하는 방식과도 같다.
- 캠페인 끝에 끝나지 않은 계약(운송 중, 채권 미수)은 손실 비율의 분모·분자에서 뺀다. 그 수를 따로 적는다. 이 수가 전체 직접 무역 계약의 15%를 넘으면 L1은 ‘진단’으로 내린다(분모 편향 때문).

- L1 상한 25%는 ‘운으로 망하는 게임’을 막는 선이다. 하한 5%는 ‘위험이 장식인 게임’을 막는 선이다.
- L3은 손실이 운만이 아니라 판단으로 줄어드는지를 본다. O1이 가르칠 수 있는 조건이다. 0.75배는 시드 20개 묶음에서 우연으로 넘기 어려운 차이로 잡은 설계 값이다.

### 3.3 J4a와 김 두 형태(묶음당 견적 수)

- 견적 수는 2G + 6이다(PLAN ‘엔진 범위 실측’). 그래서 G=3이면 12건으로 J4a를 구조적으로 실패한다.
- 이 표는 **J4a 문턱 10을 그대로 둔다.** 이유는 인지 부하다. 주마다 학생이 비교할 견적 수의 상한이고, 품목 수와 상관없이 같아야 한다.
- 따라서 (다)를 G=3으로 만들려면 TASK-0065가 자료로 견적 수를 10 이하로 맞춰야 한다. 방법은 둘 가운데 하나이고, **측정 전에** 허브가 고른다.
  1. 주선 추첨 6건 → 4건(2G+4 = 10). 주선 경제가 바뀌므로 J2·J6·J7에 영향이 크다.
  2. 김 형태를 한 묶음에 하나만 내기(묶음마다 마른김 또는 조미김). 같은 화면에서 두 형태를 견주는 학습 장면(PLAN ‘김의 HS 장면’)이 약해진다.
- 문턱을 12로 올리려면 사용자 결정으로 v2 표를 측정 전에 커밋한다.

### 3.4 1품목안의 J7

- J7은 ‘직접 무역이 주선에 묻혀 장식이 되지 않는다’를 보는 판정이다. 이 목적은 품목 수와 상관이 없다. 그래서 (나)도 **25% 그대로** 둔다.
- 예상: (나)는 묶음마다 직접 무역 견적 쌍이 하나뿐이라 비중이 떨어질 수 있다. 떨어지면 실패로 보고하고, 손잡이(5절)로 직접 무역 쪽을 올린다. 문턱은 내리지 않는다.
- R1 이상에서 J7은 손실 계약까지 넣은 실현 마진으로 센다. 손실이 많으면 직접 무역 비중도 줄어든다. 이것은 의도다. 위험 규칙이 직접 무역을 ‘하지 않는 게 나은 사업’으로 만들면 안 된다.

## 5. 경제 손잡이(미리 정한 것만)

- 손잡이는 새 rule_set 자료 값만 바꾼다. 옛 시나리오·옛 rule_set은 건드리지 않는다.
- 조정은 기준 시드로만 하고, 한 번 조정할 때마다 바꾼 값·이유·결과를 경로 5 보고서에 남긴다. **최대 3회**다. 3회 안에 맞지 않으면 실패로 보고하고 PLAN ‘판정을 다시 볼 조건’으로 넘긴다.

| 어긋남 | 돌리는 순서 |
|---|---|
| L1 < 5% | 클레임 확률 → 주간 환율 폭 → 관세 변경 폭 |
| L1 > 25% | 위 순서를 거꾸로(관세 변경 폭 → 환율 폭 → 클레임 확률) |
| L2 실패(한 층이 1%p 미만) | 그 층의 폭만 올린다. 다른 층은 두지 않는다 |
| J7 < 25% | 직접 무역 판매 기준가 마진(+5%p 단위, 올리는 쪽만) |
| J4d 밖 | 아래로 벗어나면 L1을 먼저 본다. 위로 벗어나면 Q13-2 마진 배수를 1.3에서 1.2로 |
| D 실패(한쪽이 늘 이김) | 두 번째 품목의 묶음당 최대 물량 선택지 |

- J1이 실패하면(보통 회사가 위험 규칙으로 망함) 손잡이보다 먼저 원인을 보고한다. 회복 경로 없는 손실은 설계 결함이다(딥리서치 GP7-N08).

## 7. 이 표가 정하지 않는 것

- 품목 수의 최종 선택(1품목·2품목)은 이 표의 판정 결과를 근거로 허브·사용자가 정한다. 이 표는 판정만 낸다.
- 교육 효과·흥미 판정은 알파 관문(경로 15)이 한다. 이 표의 L3은 ‘판단으로 손실을 줄일 수 있는 경제인가’만 본다. 학생이 실제로 배우는지는 알 수 없다.
