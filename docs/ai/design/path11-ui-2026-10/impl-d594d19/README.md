## 3. 실패 항목: 접은 카드 +209px

**부분별 높이(1024 터치)**

| 부분 | 높이 | 위아래 여백 |
|---|---|---|
| `fieldset`(제목 + 라디오 44px) | 67 | 0 |
| 요약 `<p>` | 23 | 15/15 |
| 등급 `<p>` | 23 | 15/15 |
| `details`(summary 44px) | 52 | 0 |

- 두 `<p>`의 기본 여백(15px)이 약 45px을 차지한다.

**고치는 법(권고, 작은 CSS·문구 수정)**
1. 요약과 등급을 한 `<p>`로 합친다. 예: ‘49일에 받음 · 41일 묶임 · 그동안 견적 공개 5번 · 거래처 B등급, 늦게 낼 수 있음’
2. `.p11 > p { margin: .25rem 0 }`을 둔다.
- 계산상 67 + 23 + 52 + 여백 약 16 ≈ 158px으로 기준 안이다. 다시 재서 확인해야 한다.
- 둘 다 `path11-screens.ts`·`path11.css` 안의 변경이라 첫 화면 예산에 영향이 없다.

## 4. 기준 밖에서 본 것(경미, 고칠지 허브 판단)

1. **대화상자 위에 머리 줄 일부와 알림 토스트가 겹친다**(`ipad-dialog-d31.png`).
   - 대화상자는 `position: fixed; inset: 4%; z-index: 100`이다.
   - 그런데 화면에서는 머리 줄 오른쪽의 ‘하루 진행’ 단추와 아래 토스트가 그 위에 보인다. 대화상자가 `#app` 안 다른 쌓임 맥락에 있을 가능성이 있다(원인 확인 안 함).
   - 머리 줄은 inert라 누를 수는 없다. 대화상자의 ‘닫기’는 왼쪽에 있어 가려지지 않는다.
2. **재무상태표 열의 행 높이가 늘어난다.** 대화상자의 두 열 격자에서 재무상태표가 손익계산서 높이만큼 늘어나 행이 벌어진다. `.p11-statements { align-items: start }`로 고칠 수 있다.
3. **400%에서 라디오 라벨이 각 180px이다.** 세 라벨이 한 줄에 `flex: 1`로 놓여 256px을 셋으로 나누고, 글이 여러 줄로 접힌다. 좁은 폭에서는 라벨을 한 줄에 하나씩 쌓으면(`flex-basis: 100%`) 높이가 줄어든다.
4. **경영 보고 칸이 길어진다.** 31일 1024에서 경로 11 블록 셋이 151 + 318 + 563px이다. 이 가운데 놓친 견적 6건 목록이 큰 몫이다. 3건 초과 접기는 날짜마다 적용되므로, 날짜가 많으면 길어진다. 알파 관찰 항목으로 둔다.
5. ‘어제 마감(30일)’과 ‘30일’이 같은 날이라 31일 아침에는 선택지 둘이 같은 결과를 낸다. 해는 없지만 둘을 하나로 합칠 수 있다.
