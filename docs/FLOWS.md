# 화면·상태·명령 흐름

## 화면 이동

```mermaid
flowchart TD
    W["세계지도"] --> C["도시 장소"]
    W --> T["거래·운송"]
    C --> P["인물·문화 활동"]
    C --> T
    P --> K["지역 기록·관계"]
    K --> T
    T --> H["회사·직원 업무"]
    H --> R["경영 보고"]
    R --> W
    C --> F["금융센터"]
    F --> R
```

## 일일 처리

```mermaid
flowchart TD
    O["일자 시작·공개 정보"] --> I["의사결정 정지"]
    I --> V{"자금·인력·용량 검증"}
    V -->|미충족| I
    V -->|충족| Q["예약·업무 실행"]
    Q --> L["운송·인도·납기"]
    L --> A["장부·결제·급여"]
    A --> M["다음 견적·보고·저장"]
    M --> O
```

문화 활동의 열람은 I에 머문다. 실제 활동은 Q에서 Task로 진행한다. 주식 기능은 P1에서 명령·현금 예약 및 일일 체결·평가 시점을 추가하며 장부를 따로 복제하지 않는다.

## 문화 경험의 결과

```mermaid
flowchart TD
    E["활동과 담당자 선택"] --> C{"위치·시간·경비 충족?"}
    C -->|아니오| D["위임·조사·일정 조정"]
    D --> E
    C -->|예| A["관찰·질문·대화"]
    A --> K["지역 지식과 자료"]
    A --> P["함께한 인물의 관계"]
    K --> N["새 질문·소개·제안"]
    P --> N
    N --> T["선택한 계약의 실제 이행"]
    T --> R["거래 신뢰와 후속 이야기"]
```

## 자사 상장 상태 — P2 설계

```mermaid
stateDiagram-v2
    [*] --> Private
    Private --> Preparing: 조달 계획과 자문
    Preparing --> Private: 중단 또는 보류
    Preparing --> Offering: 서류와 조건 준비
    Offering --> Preparing: 수요 부족·조건 조정
    Offering --> Listed: 발행·결제·주주 등록
    Listed --> Reporting: 실적·자금 사용 보고
    Reporting --> Listed: 보고와 주주 대응
```

IPO의 발행 대금은 신주 수·발행 가격·발행비용으로 검산한다. 구주 매각 대금은 매도 주주의 자금이다. 이 상태도는 가상 게임의 간략화이며 특정 거래소의 법정 절차가 아니다.

## 동료 투자와 배치

```mermaid
flowchart TD
    A["발견·면담·영입"] --> B["직원 카드와 소속팀"]
    B --> C{"직원 투자·배치"}
    C --> D["일반 교육"]
    C --> E["전문화 강화"]
    C --> F["프로젝트 편성"]
    D --> G{"자금·위치·일정 충족?"}
    E --> G
    F --> G
    G -->|아니오| C
    G -->|예| H["비용·시간 예약 후 실행"]
    H --> I["완료 보상·기록 한 번 적용"]
    I --> B
```

업무에는 참여자별 경험치, 일반 교육에는60 XP, 강화에는등급 보너스를 적용한다. 같은 효과를 중복 지급하지 않는다.
